# 게임 객체 분류

## 기획 의도

객체 정체성과 조합 가능한 기능을 분리

```mermaid
flowchart TD
    Object["게임 월드의 객체"] --> Entity["Entity<br/>판단하고 행동하는 주체"]
    Object --> Item["Item<br/>획득·소유·보관·이전 대상"]
    Object --> Prop["Prop<br/>환경을 구성하는 객체"]

    Entity --> Player["Player Entity<br/>사용자가 직접 조작"]
    Entity --> NPC["NPC Entity<br/>Humanoid · Astra · Machine · Android"]
    Entity --> Structure["Structure Entity<br/>독립 상태와 행동을 가진 시설"]

    Item --> Equipment["Equipment Item"]
    Equipment --> Weapon["Weapon"]
    Equipment --> Armor["Armor"]
    Equipment --> Accessory["Accessory"]
    Equipment --> Bag["Bag"]
    Item --> Ammunition["Ammunition Item"]
    Item --> Ingredient["Ingredient"]
    Item --> Quest["QuestItem"]
    Item --> Misc["Miscellaneous"]

    Prop --> Static["Static Prop"]
    Prop --> Interactive["Interactive Prop"]
    Prop --> Destructible["Destructible Prop"]
```

## 최상위 분류

| 분류 | 정의 | 상세 |
|---|---|---|
| Entity | 판단하고 행동하는 주체 | [Entity](%EA%B0%9D%EC%B2%B4%20%EA%B8%B0%ED%9A%8D/Entity.md) |
| Item | 획득·소유·보관·이전 대상 | [Item](%EA%B0%9D%EC%B2%B4%20%EA%B8%B0%ED%9A%8D/Item.md) |
| Prop | 환경을 구성하는 비행동 주체 | [Prop](%EA%B0%9D%EC%B2%B4%20%EA%B8%B0%ED%9A%8D/Prop.md) |

## 조합 가능한 기능

Capability는 객체의 정체성이 아니라 조합 가능한 기능

최상위 객체 분류와 구분

- Controllable
- Interactable
- Damageable
- Destructible
- Shop
- Container
- Combatant
- Movable
- Producing

| 사례 | 분류와 Capability |
|---|---|
| 상인 NPC | NPC Entity + Interactable + Shop |
| 자동 상점 시설 | Structure Entity + Interactable + Shop |
| 단순 자판기 | Interactive Prop + Shop |
| 터렛 | Structure Entity + Combatant + Damageable |
| 보관 상자 | Interactive Prop + Container |
| 총기 | Equipment Item + Weapon |
