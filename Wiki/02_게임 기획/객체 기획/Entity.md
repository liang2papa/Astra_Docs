# Entity

## 기획 의도

## 정의

고유한 상태를 바탕으로 상황·명령을 해석하고 행동하는 주체

## 유형

| 유형 | 정의 |
|---|---|
| Player | 사용자가 직접 조작하는 Entity |
| NPC | 사용자가 직접 조작하지 않는 Entity |
| Structure | 독립적인 상태·행동을 가진 시설형 Entity |

## 가능한 일

- 상황 인식과 행동 선택
- 명령에 따른 행동
- 기능에 따른 이동·전투·생산·상점 운영
- 상태 변화에 따른 행동 제한

## 분류 경계

- 이동 여부와 무관한 분류
- 피해·상호작용·상점 기능은 별도 속성
- 고정된 반응만 제공하는 환경 객체: Prop
