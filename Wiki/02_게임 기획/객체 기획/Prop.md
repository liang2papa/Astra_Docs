# Prop

## 기획 의도

## 정의

월드 환경을 구성하는 비행동 주체

## 유형

| 유형 | 정의 | 예시 |
|---|---|---|
| Static | 상태 변화가 없는 환경 객체 | 장식물·고정 구조물 |
| Interactive | 정해진 상호작용에 반응하는 객체 | 문·레버·단순 자판기·보관 상자 |
| Destructible | 피해에 따라 파괴되는 객체 | 파괴 가능한 상자·장애물 |

## 가능한 일

- 정해진 입력·사건에 반응
- Interactive와 Destructible의 동시 적용 가능
- 독립적인 판단·행동 체계 없음

## 분류 경계

- 피해·상점·상호작용 기능만으로 Entity로 분류하지 않음
- 독립적인 생산·전투·AI 상태를 가진 시설: Structure Entity
- 획득·보관·이전되는 대상: Item
