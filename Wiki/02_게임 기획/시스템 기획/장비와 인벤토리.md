# 장비와 인벤토리

## 기획 의도

귀한 탄약의 의도하지 않은 소비 방지

가방 해제 시 정리 가능한 아이템 유지

아이템 이동 중 복제·소실 방지

## 정의

- 인벤토리: 소유 아이템의 보관 공간
- 장비: 장착 슬롯에서 사용하는 아이템
- 월드 아이템: 획득하거나 버린 아이템의 월드 표현

## 보관

- 화면 그리드: 7 × 7. 최대 49칸
- 기본 사용 가능 공간: 21칸
- 아이템 또는 스택 하나당 1칸
- 아이템 크기: 모두 1 × 1
- 가방·옵션에 따른 정수 단위 공간 증감
- 최종 공간 밖 슬롯: 잠금
- 무게: 개별 무게 × 수량
- 최대 소지 중량·과적 제한: 미적용

## 장비 슬롯

Head · Body · Gloves · Shoes · Weapon 1/2 · Accessory 1/2 · Bag

## 획득·장착·해제

- 자동 장착 허용 시 호환되는 빈 장비 슬롯에 우선 장착
- 현재 가방 자동 장착 제외
- 자동 장착 불가 시 인벤토리 저장 시도
- 호환 장비 슬롯과 인벤토리 모두 가득 찬 경우 획득 실패
- 교체 시 새 장비가 있던 인벤토리 칸으로 이전 장비 이동
- 일반 장비 해제: 빈 인벤토리 칸 필요
- 가방 해제·작은 가방 교체: 공간 감소 규칙 적용

## 내구도와 파손

- 내구도는 모든 장비의 공통 상태
- 최대 내구도 `-1`: 파손되지 않음
- 내구도 0: 장비와 인벤토리에 아이템 유지
- 파손 장비: 사용 불가
- 사용 시도: `장비가 파손되었다` 표시
- 파손 장비 해제: 사용자 직접 수행

## 가방 해제와 공간 감소

1. 감소 후 공간 계산
2. 빈칸 정리
3. 새 공간 안에 들어오는 아이템 유지
4. 초과 아이템 수집
5. 해제 가방을 넣을 공간 확인
6. 공간 부족 시 가방도 드롭 대상에 포함
7. 초과 아이템을 하나의 월드 묶음으로 드롭

## 탄약 예약

- 탄약은 인벤토리에 보관
- 장전: 선택 탄종의 사용 권한과 수량을 무기에 예약
- 다른 무기와 같은 수량 중복 예약 불가
- 사용 가능 수량 = 전체 수량 − 모든 무기의 예약 수량
- 성공한 발사 시 전체·예약·장전 수량 감소
- 버리기·이전: 예약 수량을 침해하지 않는 범위만 허용
- 한 번의 장전에는 한 탄종만 사용
- 서로 다른 탄종의 혼합 장전 없음

예: AP 10발 + 일반탄 20발 보유 → AP 선택 시 AP 10발만 장전

## 재장전 탄종 선택

- 호환 탄종 하나: 자동 선택
- 여러 탄종: 아래 우선순위 적용

1. 플레이어 선호 탄종
2. 희귀도가 가장 낮은 탄종
3. 마지막 사용 탄종
4. 동일 결과를 위한 고정 기준

- 선호 탄종: 특정 스택이 아닌 탄종 자체를 저장
- 수량 0에서도 선호 설정 유지
- 재획득 시 선호 탄종으로 인식
