# 무기

## 기획 의도

## 정의

Entity가 장착하고 공격에 사용하는 Equipment Item

## 종류

Pistol · AR · SR · Grenade Launcher · SG · SMG · LMG · Laser Gun · Club · Blade

- 첫 기준 무기: 권총
- 맨손 공격: 별도 Entity 전투 행동

## 가능한 일

- 장착·무기 선택·꺼내기·수납
- 조준·공격·재장전
- 무기별 피해·사거리·반동·탄약 비용 적용

## 전투 준비

- 무기를 꺼낸 뒤 몸 방향 정렬
- 준비 완료 후 요청한 조준·공격·재장전 실행
- 꺼내기 애니메이션: 무기별 선택
- 무기 관련 행동 없이 5초 경과 시 자동 수납
- 공격·조준·재장전·무기 전환 시 수납 대기시간 재시작

## 공격 방식

| 구분 | 종류 |
|---|---|
| 전달 방식 | 실물 투사체 · 즉시 명중 · 광선 |
| 발사 방식 | 단발 · 연사 · 3점사 · 충전 · 지속 |

- 두 축의 독립 조합
- 광선 단발·즉시 명중 지속 공격도 허용
- 관통·튕김 탄환: 확장 계획

## 피해와 사거리

- 유효 사거리 안: 계산된 피해 적용
- 유효 사거리 밖: `OutOfRangeDamageMultiplier`만큼 피해 감소
- `OutOfRangeDamageMultiplier = 0.2`: 피해 20% 감소
- 지속 공격: Tick마다 피해 배율 증가 가능
- `MaxDamageMultiplierIncreasePerTick = 0`: 누적 증가 상한 없음

## 충전 공격

- 입력 시작부터 충전, 최대 충전 시간 대비 비율로 발사 여부·피해 구분
- 플레이어: 버튼 해제 시 충전 비율 20% 이하는 미발사, 20% 초과~100% 미만은 일반 피해, 100%는 1.5배 피해
- 부분 충전 피해의 선형 증가 없음. 입력 해제 시 충전량·피해 배율 확정, 실제 발사 몽타주 대기 중 완충으로 승급 없음
- 보스: 항상 100%까지 충전 후 자동 발사, 공통 완충 피해 1.5배 적용. 이전 BaseDamage 유지 안 대체
- 충전 중 걷기·추격 이동 허용. 진행 중인 NPC 충전은 Attack→Chase 전환으로 초기화하지 않음
- NPC 충전 도중 타겟이 가려지면 충전을 유지하고 완충 시 마지막 확인 위치로 발사. 가려진 타겟의 현재 위치를 새로 조회하지 않음. 유탄의 바닥 조준 설정은 저장 위치 아래 지형 사용
- 시야 상실 후 새 충전 시작은 허용하지 않으며, 타겟 기억 만료·사망·명시적 취소·무기 교체의 기존 정리는 유지
- 최소 충전 시간 = 최대 충전 시간 × 최소 충전 비율. 최대 1초이면 0.2초 이하는 발사 불가
- 외부 취소·사망·무기 교체 시 미발사
- 충전은 유탄 궤적·공격 전달·연출과 독립. 단발 유탄·충전 유탄·충전 라이플 조합 가능
- 충전 표현: 없음 / 머즐 발사체 성장 / 무기 부착 이펙트. 충전식이라는 이유만으로 실제 탄 생성·성장 강제 없음
- 프로토타입은 공통 충전 규칙과 무기별 연출 연결까지. 별도 입력·비용·쿨다운을 가진 범용 무기 고유 능력 시스템은 보류
- 기존 충전 중 주기별 탄약 소비 안은 미구현 후속. 현재는 발사 성공 시 AmmoPerShot 소비, 보스는 무소모·재장전 없음
