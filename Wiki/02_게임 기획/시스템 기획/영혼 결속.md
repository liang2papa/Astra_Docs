# 영혼 결속

## 기획 의도

## 정의

주인공과 아스트라의 영혼을 동기화하는 능력

감정 공유·대화·잠재 능력 발현

## 타입

| 타입 | 가능한 일 | 비용 |
|---|---|---|
| Possession | 아스트라 직접 조종·능력 강화 | 초당 소모 |
| DirectSkill | 아스트라의 특정 기술 단발 사용 | 즉시 소모 |
| Transform | 아스트라 형태로 변신·능력 사용 | 초당 소모 |
| Totem | 제자리에서 범위 지원 | 즉시 소모 |

## 진입·종료

- 공통 진입: 최소 게이지 충족·플레이어 지상 상태
- DirectSkill·Transform·Totem: 쿨다운 종료 필요
- 종료 조건: 타입별 개별 적용
- 비용·쿨다운·종료 조건 전문: [영혼 결속 상세](%EC%98%81%ED%98%BC%20%EA%B2%B0%EC%86%8D%20%EC%83%81%EC%84%B8.md)
- Possession 게이지 회복: 스킬 종료 후 시작
- Transform: 변신 중 이동 제한
- Totem 넉백 취소: 선택 사항
