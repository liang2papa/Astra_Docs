# 무기 조준·반동·명중률

## 기획 의도

다수의 적을 상대하는 전투에서 공중 조준 사격 허용

공중 조준과 이동 조준에 같은 명중률 기준 적용

## 조준

- 목표 방향을 기준으로 발사
- 조준 중 카메라 시야 변화
- 논리적 발사 방향과 애니메이션 표현 구분

## 반동

- Laser를 제외한 모든 무기에 반동 적용
- 성공한 공격마다 반동 누적
- 2026-10-25 사용자 선택: 마우스로 직접 보정하는 지속적인 조준 상승
- 성공한 발마다 조준 방향 상승·좌우 변화, 한 발의 변화는 짧은 시간에 나눠 적용
- 사격 종료 후 실제 조준 방향 자동 복귀 없음. 플레이어가 마우스로 보정한 방향 유지
- HUD 반동 세기 표시는 사격 종료 후 별도로 회복, 실제 조준과 분리
- HUD 누적 세기 한도에 도달해도 이후 발의 조준 반동 유지
- 기존 최종 카메라 회전 Offset·자동 복귀 정책 대체. 이동 산포와 별도 정책

## 명중률

| 상황 | 기본 명중률 |
|---|---:|
| 정지 조준 | 100 |
| 정지 비조준 | 80 |
| 이동 조준 | 80 |
| 이동 비조준 | 0 |
| 공중 조준 | 80 |
| 공중 비조준 | 0 |

- 상태 우선순위: 공중 → 지상 이동 → 지상 정지
- 상태 페널티 중복 적용 없음
- 내구도와 외부 보정 반영 후 0~100 제한
- 내구도에 따른 명중률 감쇠는 무기 DA 커브로 지정. 사용자 2026-10-24 재확인, 현재 구현은 보류. 내구도 비율과의 선형 연동으로 임의 확정하지 않음
- 유효 사거리 밖 피해 배율: 0.2

## 탄 퍼짐

- 명중률에 따른 탄도 분산
- 독립적인 적중 성공·실패 확률 아님
- 명중률이 낮을수록 발사 원뿔 반각 증가
- 최대 반각 기준: 10°
- HUD 확산 표시와 실제 탄도에 같은 기준 사용

| 명중률 | 확산 반각 |
|---|---:|
| 100 | 0° |
| 80 | 2° |
| 50 | 5° |
| 0 | 10° |

## NPC 명중률

- 무기 상태·기본 명중률에 NPC 종류·성향 보정 적용
- NPC 이동·대상 이동 페널티
- 조준 유지 시간에 따른 정확도 상승 없음
- 기본 명중률 100% 사용 안 함
- 원뿔 산포 방식, 실제 명중 확률 추첨 아님. 현재 연결 대상은 NPC 직선 총기만, 보스 유탄의 탄착 오차는 제외
