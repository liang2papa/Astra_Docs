# 무기 조준·반동·명중률

## 기획 의도

다수의 적을 상대하는 전투에서 공중 조준 사격 허용

공중 조준과 이동 조준에 같은 명중률 기준 적용

## 조준

- 목표 방향을 기준으로 발사
- 조준 중 카메라 시야 변화
- 논리적 발사 방향과 애니메이션 표현 구분

## 반동

- Laser를 제외한 모든 무기에 반동 적용
- 성공한 공격마다 반동 누적
- 연속 사격 중 누적 반동으로 조준 제약
- 사격 종료 후 정해진 시간 동안 회복
- 회복 중 재사격 시 잔여 반동에 추가 누적
- 카메라 조작 여부와 무관한 회복

## 명중률

| 상황 | 기본 명중률 |
|---|---:|
| 정지 조준 | 100 |
| 정지 비조준 | 80 |
| 이동 조준 | 80 |
| 이동 비조준 | 0 |
| 공중 조준 | 80 |
| 공중 비조준 | 0 |

- 상태 우선순위: 공중 → 지상 이동 → 지상 정지
- 상태 페널티 중복 적용 없음
- 내구도와 외부 보정 반영 후 0~100 제한
- 유효 사거리 밖 피해 배율: 0.2

## 탄 퍼짐

- 명중률에 따른 탄도 분산
- 독립적인 적중 성공·실패 확률 아님
- 명중률이 낮을수록 발사 원뿔 반각 증가
- 최대 반각 기준: 10°
- HUD 확산 표시와 실제 탄도에 같은 기준 사용

| 명중률 | 확산 반각 |
|---|---:|
| 100 | 0° |
| 80 | 2° |
| 50 | 5° |
| 0 | 10° |

## NPC 명중률

- 성향·기본 명중률 기준
- NPC 이동·대상 이동 페널티
- 조준 유지 시간에 따른 정확도 상승 없음
- 기본 명중률 100% 사용 안 함
