# 이동과 파쿠르

## 기획 의도

## 정의

지상·공중 이동과 지형 극복 행동

## 행동

| 행동 | 정의·조건 |
|---|---|
| Idle | 정지 |
| Walk | 일반 이동 |
| Sprint | 달리기 |
| Jump | 점프 |
| Falling | 공중 낙하 |
| Evade | 회피 |
| Hanging | 공중에서 정면의 잡을 수 있는 벽에 매달리기 |
| Mantle | Hanging에서 벽 위의 설 수 있는 공간으로 올라가기 |
| Vault | Hanging에서 얇은 담장 너머로 넘어가기 |

## 파쿠르 규칙

- 정면과 어깨 폭을 확보한 벽에서 Hanging 허용
- 내려온 직후 같은 벽에 자동 재매달림 방지
- Mantle: 위쪽 공간과 지지 바닥 필요
- 위쪽 공간 자체가 막힌 경우: Mantle·Vault 불가
- Vault: 벽 뒤가 낭떠러지여도 허용
- 완료 후 낙하
