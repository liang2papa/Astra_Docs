## 재개 순서와 확인 기준

1. 이 현황과 작업 규칙을 확인한 뒤 대상 담당 문서의 현재 기준 읽기
2. PT-00-5의 공통 Entity 구성·모델·모션 호환 범위 확인. 보스 일반 NPC 상속·인간형 외형을 필수로 가정하지 않음
3. 변경이 필요하면 기존 실제 코드·제공 StateTree/Blueprint와 대조 후 변경안·영향 설명. Editor 콘텐츠·빌드·프로젝트 파일 재생성은 사용자 수행
4. 아스트라·보스 기본 제작 이후 인카운터 설계. 연사·반동·교체 후 발사 잔여는 해당 QA 문서에서 별도 추적

기존 제공 자료를 먼저 활용. `D:/New Folder/대화용/ST_PlayerBaseState.T3D`·`ST_PlayerUpperState.T3D`와 별도 제공 Task·Condition·입력·GA 본문은 플레이어 문서에 정리. 전체 그래프를 다시 요청하지 않고 최신 변경·누락 노드가 필요한 경우 해당 부분만 요청

사용자 완료 확인·C++ 반영·정적 검사·빌드·Editor Compile·PIE 증거 구분. 과거 로그의 다른 Owner나 이전 빌드로 최신 변경 전체의 통과를 주장하지 않음. 최신 로그가 교체될 수 있으므로 당시 기록은 담당 QA·일일 기록의 파일명·시각 기준 확인
