# 일일 개발 리포트

일정표에는 한두 줄의 요약만 기록하고, 구체적인 작업·결정·테스트·잔여 이슈는 이 폴더에 기록합니다.

## 작성 형식

```markdown
# YYYY-MM-DD 일일 개발 리포트

## 오늘의 목표
## 완료한 작업
## 확정한 설계
## 테스트 결과
## 잔여 이슈
## 다음 작업
## 일정표용 요약

일정표용 요약은 하나의 작업씩 작성
작성 예시
■ 권총 발사 방식을 `Weapon_FireCommit` Notify 기반으로 전환 
■ 빈 탄창 상태에서 공격 시 자동 재장전 
■ 발사 중 Aim Pitch 유지, Aim Hold/Toggle·FOV C++ 기반 제작
■ 프로젝트 기획·작업 규칙·미해결 이슈 문서 정리
■ Codex ACL 충돌과 Unreal 빌드 환경 점검

```
