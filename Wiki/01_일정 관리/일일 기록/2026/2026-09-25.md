# 2026-09-25 일일 개발 리포트

## 오늘의 목표

- Inventory 없는 NPC의 탄약 검사·소비 경로 검토
- NPC 공격 STC·STT 구성 방향 정리

## 완료한 작업

### 1. NPC 발사 차단 원인 분석

- NPC 시작 무기의 최대 탄창 초기화 경로 확인
- AttackCommitHandler의 탄약 검사·소비가 InventoryComponent를 필수 요구하는 문제 확인
- STC 제거만으로 실제 발사 확정 단계의 Inventory 의존을 해결할 수 없는 구조 확인

### 2. NPC 탄약 정책 변경안 작성

- NPC는 등록 탄종과 WeaponInstance 탄창 잔량 기준으로 검사하는 변경안 정리
- NPC 발사 시 WeaponInstance 탄창만 소비하고 Player의 Inventory Reservation 소비 유지 방향 정리
- 시작 탄약 정의 누락·비호환 오류 기록 방향 정리

### 3. 공격 Task 구성 검토

- NPC 공격용 STC·STT 분리안과 기존 WeaponComponent 실행 경로 공유 방향 논의
- Draw 미사용 NPC의 초기 Ready·손 소켓 부착 처리 방향 정리

## 확정한 설계

- Player의 Inventory 예약 정책과 NPC의 탄창 소비 정책 분리
- NPC의 실제 공격 전달은 기존 WeaponComponent 경로 공유

## 테스트·검토 결과

- 현재 소스의 최대 탄창 초기화·탄약 검사·소비 경로 정적 검토
- 당일 작업 범위는 원인 분석과 변경안 작성

## 잔여 이슈

- 승인된 NPC 탄약 검사·소비 변경안 반영
- NPC 초기 무기 Ready와 실제 발사 검증
