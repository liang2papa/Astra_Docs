# 2026-10-21 일일 개발 리포트

## 오늘의 목표

- 보스 캐릭터·기본 애니메이션 제작 준비
- 캐릭터 메시 수정과 Skeleton·리타게팅 호환성 확인
- 프로토타입에 적합한 인간형 외형 적용 경로 검토

## 완료한 작업

### 1. 보스 기본 제작 범위 정리

- 보스 모델 배치·기본 자세·회전·피격·체력 감소·공통 사망의 선행 범위 정리
- 투기장 내 추적 없는 보스 전용 행동과 공통 Entity 실행 기반 재사용 검토
- 기본 캐릭터 이후 유탄·소환·전멸기·패턴 선택 및 중단 처리 순서 정리
- Sci_Fi_Character_08 Full_01과 기존·특수 애니메이션의 실제 Skeleton 확인 절차 안내

### 2. 보스 메시 수정·리타게팅 안내

- 기존 애니메이션을 보스 Skeleton에 맞추는 자동 리타겟·IK Rig·Retarget Pose·체인 대응 절차 안내
- Full_01과 Body·Head·Hat 등 개별 파츠 구성 비교
- 머리·모자·장식이 같은 머티리얼을 공유해 모자만 슬롯으로 숨길 수 없는 구조 확인
- 원본 메시 복제·FBX 내보내기·Blender 모자 형상 삭제·본과 웨이트 유지 가져오기 절차 안내
- 모자 삭제 시 선택 정점 제거와 머리 형상 잔존 여부 확인 항목 정리

### 3. Skeleton 호환·수동 리깅 시험

- SK_Mannequin과 Quinn·Manny 메시의 누락 본 경고 분석
- UE4 보스와 UE5 마네퀸의 척추·목·Twist 본 구조 차이 확인
- Blender Armature Modifier·버텍스 그룹·관절 위치·Pose Mode 변형 시험 절차 안내
- 사용자 확인: 팔 변형 시험 동작과 일부 비틀림 발생
- 프로토타입 작업량을 고려한 전신 수동 본 재배치 중단·보류
- 원본 UE4 Skeleton·웨이트 유지와 UE5 소스 메시 기반 런타임 리타겟 대안 검토

### 4. 인간형 비주얼과 수정 모델 적용

- 얼굴·헤어·복장을 갖춘 완성형 인간 캐릭터 확보 방향 논의
- UE5 지원 표기와 Manny·Quinn Skeleton 호환 표기의 구분
- Shinbi 메시의 LOD별 외형 차이와 완성된 단일 LOD 선별·무기 형상 제거 절차 안내
- 선택 메시와 Armature만 FBX 내보내기·단일 기본 LOD 가져오기 방식 정리
- 사용자 확인: 무기 제거 모델 가져오기 정상 동작

### 5. Skeleton 슬롯·Montage 연결 정리

- 자동 생성 Skeleton의 DefaultSlot만 존재하는 현상 확인
- 본 구조 유지 시 수정 전 캐릭터 원본 Skeleton 재사용 방향 안내
- Upper 슬롯·FullBody 슬롯의 Skeleton 저장 위치와 Anim Slot Manager 설정 절차 정리
- Skeleton·AnimBP Slot·Montage의 그룹·슬롯 이름 일치 및 애니메이션 호환 확인 항목 정리

## 확정한 설계

- 무기 형상 제거와 본·웨이트 변경 작업 구분
