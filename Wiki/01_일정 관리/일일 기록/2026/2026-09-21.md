# 2026-09-21 일일 개발 리포트

## 오늘의 목표

- 무기 해제 후 재장착 시 발사 불가 원인 수정 (WPN-015)
- WeaponInstance 탄종 등록·추적 구조 정리

## 완료한 작업

### 1. 무기 재장착 경로의 런타임 상태 리셋 (WPN-015)

- `BindWeaponInstance` 진입 시 AttackCommit·AttackSequence·Carry Handler의 런타임 상태를 리셋
- WeaponActionState를 Idle로 되돌리고 자동 수납 일시정지 상태를 동기화
- 재장착 시 탄약 변경 델리게이트를 해제 후 재등록
- 장전 탄수가 0인 무기 장착 시 ResolveReloadAmmunition으로 초기 탄약 Definition을 자동 등록

### 2. 무기 해제 경로 정리

- `ClearWeaponInstance`에서 발사·연속 공격·재장전·Draw·Holster 취소와 조준 해결·반동 리셋을 명시적으로 수행
- 자동 수납 타이머 정지와 Handler 런타임 상태 리셋 추가
- 해제 후 WeaponActionState를 Idle로 복귀

### 3. WeaponInstance 탄종 추적 구조

- 현재 등록 탄약 Definition과 마지막 실제 재장전에 사용된 탄약 Definition을 별도로 추적
- Gear를 떠날 때 등록 탄종·등록 탄수 해제 경로 정리

### 4. 재장전 탄종 선택 우선순위

- ReloadHandler가 인벤토리에서 탄약을 찾을 때 마지막 사용 탄종을 우선으로 찾도록 정리
- AttackCommit의 Beam 효과가 마지막 사용 탄약 Definition을 참조

## 확정한 설계

- 무기 바인딩·해제 시점에 WeaponComponent가 소유한 Handler 전체의 런타임 상태를 명시적으로 리셋 — 잔여 상태로 인한 재장착 후 발사 불가 방지
- 탄약 Definition 등록은 WeaponInstance가 소유. WeaponComponent는 Bind 시점에 0발 무기의 초기 탄종 등록만 수행
