# 2026-08-31 일일 개발 리포트

> 집계 시간: 2026-08-31 09:00 ~ 2026-09-01 09:00

## 오늘의 목표

- Inventory Menu 입력 연결
- Inventory UI 공통 리소스와 보조 Widget 기반 구성
- PlayerController와 Character의 메뉴 실행 경로 확인

## 완료한 작업

### 1. Inventory Menu 입력 에셋 구성

- `IA_ToggleInventory` Enhanced Input Action을 추가함.
- `IMC_AstraPlayerInput`에 Inventory Toggle 입력을 연결함.
- PlayerController의 InventoryMenuComponent Toggle 흐름과 입력 에셋을 연결함.
- 메뉴 입력을 Character 행동이 아니라 PlayerController 소유 UI 입력으로 처리하도록 함.

### 2. Inventory UI 공통 리소스 구성

- Inventory Slot 배경과 상태 표현에 사용할 Texture 리소스를 추가함.
- 일반 슬롯과 장비 슬롯에서 공유할 수 있는 기본 시각 리소스를 정리함.
- 실제 색상·선택·Hover·비활성 Capacity 표현은 Widget에서 적용할 수 있도록 기반을 마련함.

### 3. Tooltip과 Stack 분할 Dialog 기반 구성

- `WBP_ItemTooltip`을 생성해 Item 이름·설명·수량 등 선택 Item 정보 표시 기반을 구성함.
- `WBP_SplitStackDialog`를 생성해 Stack 분할 수량 입력 UI 기반을 구성함.
- InventoryMenuWidget의 Blueprint Event를 통해 Tooltip과 분할 Dialog를 표시하는 구조에 맞춤.

### 4. Player Blueprint 연결 점검

- `BP_PlayerCharacter`와 `BP_PlayerController`의 Inventory 메뉴 관련 연결을 갱신함.
- PlayerController가 메뉴 생성·입력 모드·Toggle을 담당하고 Character는 게임플레이 역할에 집중하도록 함.
- InventoryMenuComponent가 PlayerState의 Inventory·Gear·ItemTransfer 참조를 가져오는 실행 경로를 확인함.

## 확정한 설계

- Inventory Toggle은 PlayerController의 Enhanced Input에서 처리함.
- Tooltip과 Split Dialog는 InventoryMenuWidget이 표시하고 행동 실행은 InventoryMenuComponent로 반환함.
- Inventory UI Texture는 공통 Slot Widget에서 재사용함.

## 테스트·검토 결과

- Input Action과 Input Mapping Context 에셋 연결 상태를 구성함.
- PlayerController·Character Blueprint 변경 상태를 확인함.
- Tooltip과 Split Dialog Widget 에셋을 생성함.
- 전체 Inventory Menu 조립 전 단계이므로 최종 Open/Close·Focus·Mouse 입력 검증은 남아 있음.

## 잔여 이슈

- Inventory Slot과 Equipment Slot Widget 구현.
- Context Menu와 Equipment Slot 선택 Menu 구현.
- InventoryMenuWidget에 개별 Widget 조립.
- GameAndUI Focus 및 메뉴 종료 후 GameOnly 복원 PIE 검증.
- Tooltip·Split Dialog 데이터 표시와 입력 검증.

## 일정표용 요약

■ Inventory Toggle Enhanced Input Action·Mapping 구성  
■ Inventory Slot 공통 Texture 리소스 추가  
■ Item Tooltip과 Stack Split Dialog Widget 기반 생성  
■ PlayerController·Character Inventory 메뉴 연결 갱신
