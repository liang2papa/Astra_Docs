# 2026-09-01 일일 개발 리포트

> 집계 시간: 2026-09-01 09:00 ~ 2026-09-02 09:00

## 오늘의 목표

- Inventory·Equipment Slot Widget 구현
- Item Context Menu와 장비 슬롯 선택 UI 구성
- WorldItem 드롭·획득 테스트 레벨 연결
- 현재 구현과 장비·인벤토리 설계 차이 재점검

## 완료한 작업

### 1. Equipment Slot Widget 구현

- `WBP_EquipmentSlot`을 생성함.
- 장비 슬롯 타입과 현재 장착된 EquipmentInstance를 표시하는 기반을 구성함.
- 장비 슬롯 선택 시 Tooltip과 Gear Context Menu 요청을 InventoryMenuComponent로 전달하도록 구조를 맞춤.
- GearComponent의 Slot 변경 이벤트에 따라 표시를 갱신할 수 있도록 함.

### 2. Inventory Slot Widget 구현

- `WBP_InventorySlot`을 생성함.
- Item Icon, Quantity, 선택·Hover 및 비활성 Capacity 상태를 표현할 수 있도록 구성함.
- Inventory Slot 선택과 Context Menu 요청을 InventoryMenuComponent로 전달하도록 함.
- SlotChanged와 CapacityChanged 이벤트를 받아 개별 Slot 상태를 갱신하는 흐름에 맞춤.

### 3. Item Context Menu 구현

- `WBP_ItemContextMenu`를 생성함.
- 현재 Item 상태에 따라 장착, 해제, Stack 분할, 드롭 기능을 노출할 수 있도록 함.
- InventoryMenuComponent가 계산한 `bCanEquip`, `bCanSplit`, `bCanDrop`, `bCanUnequip` 결과를 표현에 사용하도록 함.
- 실제 실행은 Widget에서 Item을 직접 변경하지 않고 Component의 Request API로 전달하도록 함.

### 4. Equipment Slot 선택 UI 구현

- `WBP_EquipmentSlotOption`과 `WBP_EquipmentSlotSelectionMenu`를 생성함.
- 하나의 Equipment가 여러 호환 슬롯을 가질 때 대상 슬롯을 선택하도록 구성함.
- Bag Slot은 별도 Capacity Transaction이 필요하므로 일반 장착 선택 흐름에서 제외하는 현재 정책을 유지함.

### 5. Inventory Menu 조립

- `WBP_InventoryMenu`에 Inventory Grid, Equipment Slot, Tooltip, Context Menu 및 보조 Dialog를 조립함.
- InventoryMenuWidget의 Open·Close·전체 갱신·개별 Slot 갱신 Blueprint Event와 연결함.
- Menu가 닫힐 때 Tooltip, Context Menu, Slot 선택 Menu, Split Dialog 등 임시 패널을 함께 닫도록 구성함.

### 6. WorldItem 드롭·획득 테스트 구성

- `BP_ItemActor`를 생성해 WorldItemFactorySubsystem에서 사용할 월드 아이템 Blueprint 기반을 구성함.
- `CodeTest_Ver2` 레벨에 Item 획득·드롭과 UI 동작을 확인할 테스트 환경을 갱신함.
- WorldItem의 ItemInstance 보관, Collision 획득, Display Mesh 및 Pool 재사용 흐름을 테스트할 수 있도록 배치함.

### 7. PlayerController 메뉴 연결 보완

- PlayerController의 InventoryMenuComponent와 ToggleInventoryAction 노출·연결을 정리함.
- Inventory 입력이 `Started` 시점에 한 번 Toggle되도록 함.
- 메뉴가 열리면 Mouse Cursor와 GameAndUI 모드, 닫히면 GameOnly 모드로 돌아가는 C++ 실행 경로를 확인함.

### 8. 구현과 설계 차이 재검토

- InventoryMenuWidget, InventoryMenuComponent, WorldItemFactorySubsystem 및 Item 드롭 API를 기존 장비·인벤토리 설계와 대조함.
- 실제 구현된 UI·드롭·Pool 구조를 문서에 반영할 대상으로 분류함.
- Bag Capacity Transaction, SaveData, ItemBundle 정책 중 아직 구현되지 않은 범위는 완료 처리하지 않도록 구분함.

## 확정한 설계

- Slot Widget과 Menu Widget은 표현과 입력 전달만 담당함.
- InventoryMenuComponent가 UI 상태와 행동 요청의 중재자임.
- ItemTransferComponent가 장착·해제·분할·드롭 Transaction을 실행함.
- WorldItemFactorySubsystem이 WorldItem Actor Class 설정과 Pool 재사용을 담당함.
- Bag 장착·해제는 일반 Equipment 흐름과 분리해 Capacity Transaction 구현 후 연결함.

## 테스트·검토 결과

- Inventory·Equipment Slot, Item Context Menu, Equipment Slot 선택 Menu 및 전체 Inventory Menu 에셋을 구성함.
- WorldItem Blueprint와 CodeTest 레벨을 갱신함.
- PlayerController의 Toggle Action과 InventoryMenuComponent 실행 경로를 확인함.
- 실제 Item 장착·해제·분할·드롭·재획득 및 Pool 재사용 전체 PIE 결과는 추가 확인이 필요함.
