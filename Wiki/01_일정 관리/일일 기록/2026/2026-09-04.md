# 2026-09-04 일일 개발 리포트

> 집계 시간: 2026-09-04 09:00 ~ 2026-09-05 09:00

## 오늘의 목표

- Stack Split Dialog와 Inventory Menu UI 보완
- Item Tooltip 정보와 레이아웃 구성
- Item 정적 데이터의 Tooltip 표시 정보 확장
- 무기 콘텐츠 경로와 DataAsset 정리
- Unreal Editor와 Plastic SCM 연동 방식 확인

## 완료한 작업

### 1. Stack Split Dialog 보완

- `WBP_SplitStackDialog`의 수량 입력과 확인·취소 흐름을 보완함.
- 분할 가능한 최대 수량을 InventoryMenuComponent에서 전달받도록 함.
- 유효한 분할 수량만 RequestSplitStack으로 전달하고 완료 후 임시 패널을 닫도록 구성함.
- 빈 Slot 부족 또는 잘못된 수량 입력 시 실패 처리를 유지함.

### 2. Inventory Menu 레이아웃 보완

- `WBP_InventoryMenu`의 Inventory Grid와 Gear 영역 배치를 정리함.
- Tooltip, Context Menu, Equipment Slot Selection Menu와 Split Dialog가 동일 Menu 계층에서 표시되도록 구성함.
- 메뉴 내부 Panel의 역할을 목록 배치, 겹침 배치, 자유 배치 및 크기 제한으로 구분해 정리함.
- Widget별 Anchor, Alignment, Padding 및 Desired Size 적용 방향을 검토함.

### 3. Item Tooltip 구현·레이아웃 정리

- `WBP_ItemTooltip`의 Item 이름, 설명, 수량, 개당 무게와 총무게 표시 구성을 보완함.
- 아이콘·슬롯처럼 고정 크기가 필요한 영역은 SizeBox로 제한하고 텍스트는 내용에 따라 확장되도록 구성함.
- Vertical·Horizontal Box는 목록 정렬, Overlay는 겹침, Canvas Panel은 좌표 기반 자유 배치 용도로 구분함.
- 다국어 텍스트 길이 변화를 고려해 Tooltip 전체를 고정 좌표로만 구성하지 않도록 함.

### 4. Item DataAsset Tooltip 정보 확장

- `UItemDataAsset`의 Tooltip 표시와 관련된 공통 필드를 보완함.
- Item Icon, 이름, 설명, 수량 및 Weight 정보를 UI에서 공통으로 조회할 수 있도록 구조를 확인함.
- Inventory Slot과 Tooltip이 동일한 ItemDataAsset·ItemInstance 정보를 사용하도록 함.

### 5. 무기 콘텐츠와 DataAsset 정리

- 권총 콘텐츠를 Equipment/Weapon 경로 기준으로 정리함.
- Base Pistol과 Sci-fi Pistol의 Mesh, Material, Texture 및 Icon 에셋을 장비 무기 구조에 맞게 정리함.
- Base Pistol·AR DataAsset과 Weapon Crosshair DataAsset의 참조를 갱신함.
- 중복된 이전 Item/Weapon 경로가 함께 존재하는 상태를 확인하고 참조 검증 대상으로 남김.

### 6. Unreal Editor·Plastic SCM 연동 확인

- Unreal Editor의 Plastic SCM 연동이 별도 저장소가 아니라 기존 로컬 Workspace를 사용하는 또 하나의 클라이언트임을 확인함.
- Asset Checkout·History·Diff는 Unreal Editor에서, 전체 Pending Changes·Branch·Merge·Changeset 관리는 Plastic GUI에서 병행하는 방식을 정리함.
- Unreal Editor에서만 연동을 끊을 경우 `Run Without Source Control`을 사용하고 기존 Workspace와 Pending Changes에는 영향을 주지 않는다는 점을 확인함.

## 확정한 설계

- Tooltip은 ItemDataAsset의 정적 정보와 ItemInstance의 수량을 조합해 표시함.
- UMG에서 SizeBox는 크기 제약, Border는 배경·Padding, Box Panel은 자동 배치, Overlay는 겹침, Canvas Panel은 자유 배치를 담당함.
- 무기 콘텐츠는 Item/Equipment/Weapon 소유 구조를 기준으로 정리함.
- Unreal Editor와 Plastic GUI는 동일 Workspace를 공유하되 역할을 나눠 사용함.

## 테스트·검토 결과

- ItemDataAsset 공통 정보와 Tooltip 표시 구조를 대조함.
- PlayerHUD, Weapon DataAsset 및 Crosshair 관련 참조 에셋을 함께 확인함.
- 무기 콘텐츠 이동 후 Redirector·Reference Viewer·Asset Audit 검증은 추가로 필요함.
- Tooltip의 다양한 이름·설명 길이와 해상도별 레이아웃 검증은 남아 있음.
