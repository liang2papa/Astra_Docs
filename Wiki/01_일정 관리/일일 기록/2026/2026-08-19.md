# 2026-08-19 일일 개발 리포트

> 집계 시간: 2026-08-19 09:00 ~ 2026-08-20 09:00

## 오늘의 목표

- 권총 Aim의 StateTree·Gameplay Ability 실행 구조 완성
- 무기별 Aim FOV와 Hold/Toggle 입력 기반 구현
- 조준 중 발사, 수납 상태 조준, Sprint 중 조준 전환 규칙 정리

## 완료한 작업

### 1. Aim StateTree 구조 정리

- `STC_CanAim`은 `Ready → Aim` 전이 가능 여부만 검사하도록 역할을 확정함.
- `STT_WeaponAim`은 `GA_WeaponAim` 활성화, Aim 진입 이벤트 발행, Ability 활성 상태 감시 및 종료 시 Ability 취소를 담당하도록 정리함.
- `EntityStateMediatorComponent`에 Blueprint에서 호출할 수 있는 `CancelAbilityByTag()`를 추가함.
- `STT_WeaponAim.ExitState`에서 `Ability.Weapon.Aim`을 명시적으로 취소할 수 있도록 기반을 마련함.
- StateTree Task 종료 결과와 실제 Transition 명칭을 구분하고, Aim 종료에는 `On State Completed → Ready` 전이를 사용하도록 정리함.

### 2. Blueprint 작업 규칙 구체화

- Blueprint 안내에서 임의의 `Is Valid` 방어 노드를 기본으로 추가하지 않기로 함.
- 실제 노드, 전이 설정, 전체 실행 흐름을 `[노드]`, `[전이 설정]`, `[실행 흐름]`으로 명확히 구분하기로 함.
- 에디터에 없는 축약 명칭을 사용하지 않고 Gameplay Tag, 함수, 이벤트 및 Transition 명칭을 정확히 표기하기로 함.
- `BP_PlayerCharacter`에서 `IA_Astra_Aim`의 Started를 `Request Weapon Aim Started`, Completed/Canceled를 `Request Weapon Aim Completed`에 연결하도록 정리함.
- `StartupAbilityClasses`에 `GA_WeaponAim`을 등록하는 절차를 확인함.

### 3. Aim 상태와 Fire 계층 설계

- 조준 중 Fire가 발생해도 `GA_WeaponAim`과 `State.Combat.Aiming`이 유지되어야 함을 확정함.
- Aim과 Fire를 단순 형제 상태로 전이하면 Aim의 ExitState에서 Ability가 취소되므로, Aim 아래에 `AimReady`와 `AimFire`를 두는 계층 구조를 설계함.
- 비조준 발사는 기존 `Ready → Fire → Ready` 흐름을 유지하고, 조준 발사는 `AimReady → AimFire → AimReady`로 처리하도록 함.
- 수납 상태에서 Aim 입력 시 Pending Aim을 저장하고 Draw 완료 후 Aim으로 진입하도록 함.
- Sprint 중 Aim 진입 시 `Event.State.Upper.AimEntered`를 통해 Locomotion Sprint 취소 명령을 전달하도록 함.

### 4. 무기별 FOV 및 PlayerCameraManager 구현

- `WeaponDataAsset`의 `AimInputMode`, `AimFOV`, `AimFOVInterpSpeed`를 무기별 조준 설정으로 사용함.
- `AAstraPlayerCameraManager`에 `StartAimFOV`, `StopAimFOV`, `UpdateCamera`를 구현함.
- 조준 시작 시 무기별 FOV로 보간하고, 조준 종료 시 기존 기본 FOV로 복귀하도록 함.
- FOV 복귀 도중 다시 조준해도 최초 기본 FOV가 유지되도록 처리함.
- PlayerCharacter Tick에서 직접 수행하던 FOV 보간을 제거해 카메라 책임을 PlayerCameraManager로 이동함.
- Aim C++ 변경 후 `Astra_SoulLinkEditor Win64 Development` 빌드 성공을 확인함.

## 확정한 설계

- `STC_CanAim`은 전이 조건, `STT_WeaponAim`은 Aim 상태 실행과 GA 활성화, `GA_WeaponAim`은 조준 행동 수명주기를 담당함.
- 조준 중 Fire는 Aim 부모 상태를 유지하는 자식 상태 전이로 처리함.
- 무기별 Aim 입력 방식과 FOV 값은 `WeaponDataAsset`이 소유함.
- 카메라 FOV 보간은 PlayerCharacter가 아니라 PlayerCameraManager가 담당함.
- Aim 진입은 Sprint를 취소하지만 Aim 종료 후 Sprint를 자동 복구하지 않음.

## 테스트 결과

- `CancelAbilityByTag()` 추가 후 UE 5.8 Editor 빌드 성공.
- PlayerCameraManager 기반 Aim FOV 구현 후 UHT, C++ 컴파일 및 DLL 링크 성공.
- Aim 입력, Startup Ability, StateTree 및 GA 연결에 필요한 에셋과 노드 존재 확인.

## 잔여 이슈

- `GA_WeaponAim` Blueprint의 ActivateAbility·EndAbility 전체 연결 및 실제 플레이 검증.
- `Aim → AimReady → AimFire` StateTree 계층 구성과 Hold/Toggle 회귀 테스트.
- 조준 중 Fire 완료 후 Aim 유지 여부 확인.
- 수납 상태 Aim 입력 후 Draw와 Aim이 연속 실행되는지 검증.
- Sprint 중 Aim 진입 시 Sprint 취소 이벤트 검증.
- PlayerCameraManager 참조를 GA에서 반복 탐색하지 않는 구조로 추가 정리.
