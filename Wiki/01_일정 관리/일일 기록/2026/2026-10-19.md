# 2026-10-19 일일 개발 리포트

## 오늘의 목표

- 권총·라이플 장착 보정과 무기별 상체 포즈 연결
- 인간형 AnimBP 갱신의 C++ 이관
- 손에 든 상태의 무기 교체 동작 보완

## 완료한 작업

### 1. 라이플 소켓·Transform과 탄약 정의 정리

- 손·등 수납 소켓과 무기별 EquippedMeshTransform·HolsteredMeshTransform 조정 방식 안내
- 기존 WeaponMesh 미리보기의 Visible 설정과 실제 장착 시 표시 처리 확인
- 라이플 획득 중 강제 종료의 AmmoTypeTag 누락 원인 확인
- WeaponAmmo.csv 라이플 행에 Item.Ammunition.556mm 반영
- CSV 반영과 기존 DataAsset 필드 저장의 별도 적용 절차 안내

### 2. 인간형 AnimInstance C++ 이관

- AstraHumanoidAnimInstance와 AnimationData 기반 인간형 애니메이션 갱신 구조 반영
- 무기 종류·Carry·실제 부착 상태 변경의 이벤트 기반 갱신
- 이동·낙하·매달림·조준 보간·보정값 계산의 C++ 갱신 경로 구성
- 캐릭터 Blueprint의 명시적 초기화 책임 유지와 InitializeForEntity 연결 안내
- 재초기화·종료 시 이벤트 구독 정리 경로 구성

### 3. 무기 교체와 AnimGraph 연결

- 손에 든 무기 교체 시 새 무기의 손 소켓 부착·Ready 유지 C++ 반영
- 기존 InitABPClass에서 InitializeForEntity 호출 및 ABP AimInterpSpeed 전달 방식 정리
- AnimGraph·상태 머신의 기존 변수 참조를 AnimationData로 교체하는 대응표 작성
- 무기별 Idle 선택 → UpperBody Slot → 무기별 AimOffset → 상하체 Blend 연결 안내
- 중복 EventGraph 계산 제거 순서와 기존 초기화 함수 유지 범위 정리
- Lyra 라이플 Idle·AimOffset 샘플·사격 시퀀스·Montage 역할과 Slot 차이 확인

## 확정한 설계

- 무기·Carry·부착 상태는 이벤트 갱신, 이동·조준 연속값은 NativeUpdateAnimation 갱신
- AnimGraph와 포즈·Slot·에셋 선택은 Blueprint 유지
- 캐릭터의 명시적 초기화와 ABP의 보간값 튜닝 책임 유지
- 무기별 장착·수납 보정은 DataAsset 저장
