# 2026-10-09 일일 개발 리포트

## 오늘의 목표

- NPC 지상 상태·의도 복구와 수동 재장전 정리

## 완료한 작업

### 1. NPC 상태 책임과 휴대 정책 정리

- Controller의 BrainState를 중단 중에도 유지되는 행동 의도로 정의
- Base Idle은 정지, Patrol은 이동·도착 대기, Chase는 타겟·기억 위치 접근, Falling은 지상 실행 중단으로 구분
- Upper의 무기 휴대 상태와 하체 행동 분리
- Idle·Patrol의 강제 Holster 요청 제거 및 무기 활동 갱신으로 자동 수납 방지

### 2. 착지 후 현재 의도 복구 C++ 반영

- GroundedEntered 사건과 EventBus → Mediator → NPCCharacter → Controller 연결 추가
- Controller 현재 BrainState에 따른 Patrol·Chase·Stop 재발행 구현
- Ground 부모 Task 첫 Tick 알림 후 완료 및 완료 판정 제외 구성 안내
- Ground 자식 전환 시 준비 알림 재실행 방지 설정 정리

### 3. 추적 종료 후 순찰 복귀 해결

- Ground 부모의 Patrol·Chase·Stop 명령 전이와 지속 상태 Running 유지 구성 정리
- Brain Idle에서 CancelChase와 Patrol 동시 발신으로 인한 명령 충돌 가능성 확인
- 중복 추적 종료 Task 제거 후 Patrol 명령으로 직접 전환·Chase Exit에서 이동 정리
- 사용자의 추적 종료 후 Patrol 복귀 정상 확인

### 4. 수동 재장전 조건 원인 확인

- STC_CanReload가 ShouldAutoReload 결과를 반환해 잔탄 상태에서 수동 재장전을 차단하는 원인 확인
- 수동 조건을 CanReloadWeapon으로 교체하는 Blueprint 연결 안내
- Reload 명령 기반 수동 전이와 AttackStarted·빈 탄창 기반 자동 전이 분리 안내

### 5. 문서 보완 항목 검토

- NPC 기획·설계·애니메이션·QA·Context 진단·이슈·로드맵의 과거 수납 정책과 상태 복귀 안내 대조
- 사용자 확인 완료 항목과 DamageLook·착지 시나리오 추가 검증 항목 정리
