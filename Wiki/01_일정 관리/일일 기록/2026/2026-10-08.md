# 2026-10-08 일일 개발 리포트

## 오늘의 목표

- NPC 재장전·추적 복귀 문제 해결
- 마지막 확인 위치 추적과 Idle 순찰·피격 방향 확인 구현
- 시야 상실·재발견 시 무기 쿨다운 유지

## 완료한 작업

### 1. 재장전과 추적 문제 점검

- 사용자의 NPC 사격 정상 동작 확인
- bCanReload 설정 수정 후 사용자 재장전 수행 확인
- 사거리 이탈 후 추적 상태만 표시되는 이동 정지 증상 점검

### 2. 마지막 확인 위치 추적 C++ 구현

- 타겟 가시 여부·마지막 확인 위치·상실 대기·이동·탐색 단계 관리 추가
- 타겟 차폐·상실 시 공격 중단 후 마지막 확인 위치 접근 처리
- NavMesh 경로와 부분 경로를 통한 접근 가능 지점 계산
- 도착 후 기존 GiveUpTime 동안 탐색·대기 후 Idle 복귀 정책 적용
- LostTargetMoveDelay를 기존 DataAsset 성향 구조에 추가
- 기존 Blueprint Chase Task에서 요청·갱신·취소 API 호출 방식 유지

### 3. 추적 연결과 컴파일 오류 수정

- 변수명 변경 후 잔존 Pawn 참조를 NPCPawn으로 수정
- 사용자 빌드 성공 확인
- Attack → Idle의 Has Target Memory 역조건 누락 확인 및 수정 안내
- Chase Task의 Enter 요청·Tick 갱신·Exit 취소 연결 절차 정리
- 사용자의 추적 문제 해결 확인

### 4. Idle 순찰·홀스터와 피격 방향 확인 구현

- 최초 Possess 위치 중심의 도달 가능한 무작위 순찰·도착 대기·실패 재선택 API 추가
- Idle 진입 시 홀스터 수납 요청과 Patrol 명령 발행 처리
- 피격 방향 저장·이동 중지·회전·시야 확인 C++ 경로 추가
- 피격만으로 타겟을 획득하지 않고 시야 감지 후 추적·공격하는 정책 적용
- 순찰 반경·대기·도착 거리·피격 방향 확인 시간·회전 속도를 기존 DA 성향에 추가

### 5. 시야 상실 시 쿨다운 초기화 문제 수정

- 공격 취소 시 기존 WeaponDataAsset의 발사 쿨다운 유지
- CanAttackWeapon의 쿨다운 검사 추가
- Ready 초기화·피격 대기 조건 보완과 NPCCombat 진단 로그 추가
- 사용자의 재빌드·재실행 후 문제 없음 확인

### 6. 순찰 Blueprint 연결 점검과 문서 정리

- NPC Idle Command의 배치 위치를 ST_AIBrain Idle로 명확화
- Base Patrol Task에서 Pawn.GetController 또는 Actor.GetAIController로 Controller 확보 안내
- Actor를 Controller로 직접 Cast하는 오류 지점 확인
- Idle → Patrol 이벤트 전이와 Payload 바인딩 확인
- Patrol → ChaseWalk 전이 추가와 Cast 실패 로그·실패 처리 안내
- NPC 추적·순찰·피격 연결 문서의 단문형·명사형 종결 정리

### 7. 당일 문서 최신화

- 10월 8일까지의 대화·현재 소스 기준 NPC 발사·재장전·추적·순찰·피격 반응 문서 갱신
- 무기 쿨다운·탄약 정책과 컴포넌트 역할 정리
- 완료 확인과 연결 대기 항목 구분 및 Context·Controller 연결 방법 기술 위키 추가
- 문서 링크 1,224개·페이지 내부 링크 31개 검사 오류 없음 확인

## 확정한 설계

- Brain을 제외한 이동·행동 Task는 Blueprint 구성 유지
- Controller C++이 타겟 기억·타이머·경로·이동·회전 실행 소유
- 기존 GiveUpTime과 기존 DA 성향 구조 재사용
- Idle은 홀스터 수납, 피격 방향 확인 후 시야 감지 시 전투 진입
