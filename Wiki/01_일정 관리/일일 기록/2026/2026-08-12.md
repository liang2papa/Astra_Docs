# 2026-08-12 일일 개발 리포트

> 작업일 기준: 2026-08-12 08:00부터 2026-08-13 08:00 전까지

## 오늘의 목표

- 권총 장착·휴대 상태 구조 완성
- 상체 권총 포즈와 Equip/Holster Montage 연결
- Physical Projectile 기반 권총 발사의 1차 경로 구성
- StateTree와 GAS, WeaponComponent의 책임 분리 검증

## 완료한 작업

### 1. 권총 장착·휴대 상태 구조

- Weapon Carry StateTree를 `Holstered`, `Drawing`, `Ready`, `Holstering`으로 분리함.
- STC는 전이 가능 여부만 검사하고 STT가 몽타주, 소켓 이동, 타이머를 실행하도록 책임을 분리함.
- `WeaponDataAsset`은 정적 정의, `WeaponModel`은 무기별 탄약 인스턴스, `WeaponComponent`는 장착·표현·실행을 담당하도록 소유 구조를 확정함.
- `WeaponSocket_R`, `PistolHolsterSocket`, `Muzzle` 연결을 확인함.
- Equip/Holster Montage Notify를 기준으로 무기를 손과 홀스터에 부착하도록 구성함.
- Ready 상태의 자동 수납 타이머와 `PendingWeaponAction` 예약 실행 구조를 구현함.

### 2. 권총 Anim Blueprint

- `ABP_Unarmed`에 `UpperBody` Slot을 생성하고 Montage가 상체에만 적용되도록 연결함.
- `Layered Blend Per Bone`을 사용하여 하체 Locomotion과 권총 상체 애니메이션을 결합함.
- 무기를 손에 든 동안 `Pistol_Idle`이 유지되고, 수납 시 비무장 상체로 복귀하도록 구성함.
- Draw/Holster 전환은 Blend In/Out 0.2초와 Exponential In 설정으로 임시 안정화함.
- Draw 원본 애니메이션과 Pistol Idle의 시작·종료 포즈가 정확히 일치하지 않는 문제를 확인하고 Blend 설정으로 임시 완화함.

### 3. Holster 동작

- 전용 Holster Montage를 연결함.
- `Weapon_AttachToHolster` Montage Notify에서 무기를 홀스터 소켓으로 이동하도록 구성함.
- Notify 누락 또는 몽타주 중단 상황을 위한 종료 fallback을 연결함.
- 전용 Notify가 정상 실행되도록 몽타주 Slot과 재생 방향을 수정함.

### 4. 권총 발사 1차 기반

- `IA_Astra_Attack`의 Started 입력에서 무기 발사를 요청하도록 연결함.
- 무기가 수납되어 있으면 Fire를 `PendingWeaponAction`으로 예약하고 Draw 완료 후 실행하도록 구성함.
- Ready 상태에서는 Upper Fire 흐름과 `GA_WeaponFire`를 활성화하도록 연결함.
- AbilitySystemComponent와 `GA_WeaponFire`의 기초 연결을 구성함.
- `WeaponComponent`가 탄약 소비, Projectile 생성, Fire Sound, Muzzle VFX, 반동 요청을 담당하도록 함.
- `ProjectileDataAsset`과 `ProjectileController` 기반 Physical Projectile 경로를 구성함.
- 테스트용 Projectile에 기본 Sphere Mesh를 사용할 수 있도록 함.

### 5. 이동 회전 방식

- 무기를 손에 든 상태에서는 Controller Desired Rotation을 사용하도록 함.
- 무기를 수납한 상태에서는 이동 방향 회전을 사용하도록 함.
- 무기를 꺼내는 순간 캐릭터가 카메라/Aim 정면을 향하도록 전환함.
- 무기 상태의 Yaw 회전 속도를 720으로 설정함.
- Sprint 중 Fire 입력 시 Sprint를 해제하고 Walk로 전환하는 방향을 정함.

### 6. 오류 수정 및 안정화

- Anim Blueprint에서 WeaponComponent가 None이던 문제를 `GetComponentByClass`와 PlayerCharacter의 Blueprint 노출 설정으로 해결함.
- `PlayerCharacter`의 WeaponComponent 참조를 Blueprint에서 접근할 수 있도록 노출 수준을 조정함.
- Holster Montage Notify가 있음에도 fallback 경고가 발생하던 문제를 전용 Montage Notify와 Slot 설정으로 해결함.
- CharacterMovement 지역 변수 이름이 멤버를 가리던 C4458 오류를 수정함.
- `IAbilitySystemInterface` 관련 Visual Studio 표시는 IntelliSense 문제이며 Unreal Build에는 문제가 없음을 확인함.
- Unreal Engine 5.8 Development Editor 빌드에 성공함.

## 확정한 설계

- WeaponCarryState는 별도 StateTree를 원본으로 유지함.
- UpperAction의 Fire, Reload, Aim은 GAS가 실행함.
- StateTree는 전이와 행동 선택, GAS는 비용·쿨다운·취소를 포함한 실제 실행, WeaponComponent는 무기 도메인 처리를 담당함.
- PlayerCharacter는 입력 라우팅과 컴포넌트 조립 중심의 Shell로 점차 축소함.
- WeaponComponent는 장착과 발사 실행, WeaponModel은 개별 무기의 현재 탄약 원본을 담당함.
