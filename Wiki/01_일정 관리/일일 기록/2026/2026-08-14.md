# 2026-08-14 일일 개발 리포트

## 오늘의 목표

- 플레이어 전투 기반을 StateTree와 GAS로 정리
- Weapon Carry와 Upper Action 흐름 연결
- 권총 기본 발사까지 확인

## 완료한 작업

### GAS 기반 구조

- `AAstraPlayerState`가 플레이어 ASC와 Entity/Player AttributeSet을 소유하도록 구성했습니다.
- Pawn 교체 이후에도 플레이어 자원과 Ability 쿨다운이 유지되는 방향을 확정했습니다.
- GameplayTag 기반 Input, Ability, Movement, Combat, Weapon Carry 상태를 추가했습니다.
- 구체 Gameplay Ability는 C++ 클래스보다 Blueprint 자산을 우선하기로 변경했습니다.
- `GA_AstraBase → GA_WeaponBase → GA_WeaponFire` Blueprint 계층을 구성했습니다.
- GA Weapon Base에서 Avatar와 WeaponComponent를 캐싱하는 함수를 구성했습니다.

### StateTree 구조

- 기존 WeaponCarry StateTree와 UpperAction 개념을 `ST_UpperState` 하나로 통합했습니다.
- Upper 상태를 Holstered, Drawing, Ready, Holstering, Fire, Aim, Reload로 정리했습니다.
- `STC_CanDrawWeapon`, `STC_CanFire`, `STT_Fire`를 구성했습니다.
- STC는 사전 전이 검사, STT는 Event 게시와 GA 활성화 요청을 담당하도록 역할을 분리했습니다.
- STC/STT 바인딩을 `Actor + EntityContext` 중심으로 단순화했습니다.
- PlayerContext `None` 오류의 원인이 Blueprint Cast가 아니라 StateTree 인스턴스 바인딩/초기화 순서임을 확인하고 연결을 수정했습니다.

### EntityStateMediator

- `EntityStateMediatorComponent`를 상·하체 StateTree의 이벤트 허브로 사용했습니다.
- Upper Fire/Aim 진입 시 Base Sprint를 취소하도록 연결했습니다.
- Base Sprint/Airborne/Traversal 진입 시 Upper Action 취소와 Force Holster를 전달하도록 구성했습니다.
- 피해와 사망 이벤트가 상·하체 상태와 Ability 취소로 연결되는 기반을 추가했습니다.

### 권총 발사

- Attack 입력이 Draw 예약을 거쳐 Upper Fire State로 진입하고 `GA_WeaponFire`를 활성화하는 흐름을 연결했습니다.
- `STT_Fire`의 `Publish Simple`이 Fire 진입 이벤트이며 Ability 활성화와 별도라는 점을 확정했습니다.
- 카메라 Ray로 AimTarget을 구하고 Muzzle에서 해당 목표로 Projectile을 발사하도록 수정했습니다.
- 카메라 Trace에서 소유 Character와 장착 무기를 제외했습니다.
- Muzzle Socket 축을 회전해도 해결되지 않던 역방향 발사를 Look-at 방향 계산으로 수정했습니다.
- 실제 Projectile 발사가 정상 방향으로 동작함을 확인했습니다.

### Sprint 충돌

- Sprint 중 Fire 입력 시 Sprint → Walk → Fire 흐름을 구성했습니다.
- Fire 종료 후 Sprint가 자동 재개되지 않도록 Sprint 입력/토글 상태를 취소하는 전용 경로를 추가했습니다.

## 확정한 설계

- StateTree는 행동 흐름을 선택하고 GAS는 실제 전투 행동과 수명을 담당합니다.
- STC 사전 검사는 사용자 경험과 전이 선택을 위한 것이며 GA의 실행 안전 검사를 제거하지 않습니다.
- PlayerCharacter가 하위 상태를 직접 조정하지 않고 Mediator가 GameplayTag 이벤트로 중재합니다.
- Blueprint 자산 생성과 연결은 사용자가 수행하고, C++는 공통 기반과 안전장치를 담당합니다.
