# 2026-10-14 일일 개발 리포트

## 오늘의 목표

- 프로토타입 제작 계획 작성과 에셋·애니메이션 선행 작업 확정

## 완료한 작업

### 1. 프로토타입 제작 계획 작성

- 12월 11일 테스트 빌드·12월 15일 최종 목표와 주 30시간 기준 일정 작성
- 검증·수정·패키징 시간 확보 및 일정 관리 페이지 연결
- 보스 명중 → 에너지 수급 → 좀비 정리 → 탄약 회수 → 보스 공격 순환 정리

### 2. 보스전·아스트라 규칙 확정

- 아스트라 3종 동행·체력 유지와 직접 공격 타겟 제외
- 모든 파티원 지속 회복·모든 아군 실드 보호·공격형 광역 피해 역할 정리
- 같은 기술 사용 중 재사용 금지·다른 기술 동시 사용·별도 쿨다운 없음 규칙 반영
- 보스 명중과 자연 회복 기반 소울 에너지 수급 및 공격형·좀비 수급 제외

### 3. 필드·탄약·회차 정책 확정

- 동일 맵 일반 구역·보스 구역과 별도 입장 로딩 없는 구성 확정
- 좀비 사망 탄약 상자 드롭과 플레이어 접촉 획득 확정
- 보스 처치 후 두 재시작 발판·플레이어 사망 후 두 선택 UI 구성 정리
- 보스 재시작과 전체 재시작의 공통 요청 경로·정리 대상 정의
- 보스 진입·실제 전투 시작 시각 기록과 UI 경과 시간 표시 계획

### 4. 리소스 확보 선행 순서 변경

- 사용자의 Lyra 애니메이션 임포트 진행 기록 반영
- Lyra 사용 클립 선별 → 보스 모델·애니메이션 → Unity 아스트라 리소스 → 기타 필수 에셋 확보 순서 확정
- 기존 라이플 모델·애니메이션 확보 확인과 적용 작업 분리
- 에셋 확보·애니메이션 개선을 회차·타이머 구현보다 앞선 선행 작업으로 이동

### 5. 총기 모션·시선·전신 사망 개선 목록 정리

- 권총·라이플의 대기·조준·발사·재장전 모션과 무기 교체 시 포즈 전환 작업 추가
- Lyra 기반 사격 시작·반복·종료·수납·이동·회피 후 복귀 시퀀스 점검 범위 정리
- 플레이어 머리의 카메라 조준점 추종과 NPC 순찰 중 하향 시선 문제 기록
- 생존 상체가 남고 하체만 쓰러지는 플레이어·NPC 사망 증상 기록
- 전신 사망 포즈 우선 출력·조준·시선·상체 블렌드 해제의 검증 항목 추가

### 6. 착수 체크리스트와 계획 문서 검증

- 좀비 근접·사망, 보스 패턴 애니메이션, 유탄·착탄 경고·폭발, 아스트라·기술·UI·발판 제작 항목 정리
- BossEncounterComponent의 회차·시간 관리 변경안 작성
- 최종 선행 순서 변경에 따라 회차 구현 착수 시점을 에셋·모션 작업 이후로 조정
- 10월 23일 선행 작업 통과 목표와 후속 일정 재산정 조건 반영

## 확정한 설계

- 에셋 확보·총기 모션·시선·전신 사망 개선 우선
- 탄약은 플레이어 접촉 획득, 보스 필드는 동일 맵 구성
- 기술·회차·재시작 구현은 확정 계획 기준 후속 작업

## 테스트·검토 결과

- 제작 계획 문서·연결·시간 배분 검토 완료
- 사용자 확인: Lyra 임포트 진행과 라이플 모델·애니메이션 확보
- 총기 모션·시선·전신 사망 개선은 작업 목록과 완료 기준 정리 단계
- BossEncounterComponent 실제 구현 완료 기록 없음
