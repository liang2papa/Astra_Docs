# 2026-09-11 일일 개발 리포트

> 집계 시간: 2026-09-11 09:00 ~ 2026-09-12 09:00

## 오늘의 목표

- WeaponComponent 기능별 Handler 분할 마무리
- Weapon1·Weapon2 선택과 빈 슬롯 맨손 전환 구현
- Upper·Lower StateTree의 Sprint·Evade·Ready 연동 보완

## 완료한 작업

### 1. WeaponComponent Handler 분할 확장

- Handler 공통 기반과 Aim, Reload, Carry Handler를 갱신함.
- 공격 입력 순서와 반복 공격 상태는 `AttackSequenceHandler`가 담당하도록 분리함.
- 공격 1회의 데이터 확정, 전달 실행과 탄약 소비는 `AttackCommitHandler`가 담당하도록 분리함.
- Projectile, Hitscan과 Beam 공격 전달에 필요한 공통 요청·결과 타입을 정리함.
- ProjectileFactorySubsystem이 신규 공격 확정 데이터 경로를 사용하도록 연결함.

### 2. 무기 슬롯 선택 구현

- Player 입력에 Weapon 선택 Action을 연결함.
- GearComponent에 활성 Weapon Slot 설정과 Weapon1·Weapon2 순환 선택 경로를 추가함.
- 활성 슬롯 변경 시 PlayerCharacter와 WeaponComponent가 현재 WeaponInstance를 다시 바인딩하도록 연결함.
- 선택한 슬롯이 비어 있으면 정상적인 활성 슬롯으로 인정하고 WeaponComponent를 해제해 맨손 상태로 전환하도록 함.
- 무기 전환 Cooldown 동안 중복 전환 요청을 차단함.

### 3. 무기 Carry 상태와 맨손 전환 보완

- 빈 슬롯 선택 시 Upper StateTree가 Holstered 상태로 동기화되도록 정리함.
- 무기가 없는 상태에서도 Holstered 진입은 정상 성공으로 처리하도록 Carry 흐름을 보완함.
- 맨손 회피 시 불필요한 추가 ForceHolster 요청을 차단함.
- Holster Task와 PlayerCharacter Blueprint를 현재 Carry 상태 전환에 맞춰 갱신함.

### 4. Sprint·Evade·Ready 상태 연동 설계 및 C++ 준비

- 게임 시작 시 자동 `RequestWeaponDraw()`를 제거해 최초 상태가 Holstered로 유지되도록 함.
- Upper StateTree의 Ready 진입 사건으로 `ReadyEntered`를 추가함.
- Ready 진입 성공 시 중재자가 정책 판단 없이 Lower StateTree에 `CancelSprint` 명령을 전달하도록 연결함.
- Sprint와 Evade 허용 여부는 중재자가 아닌 StateTree Condition이 판단하도록 책임을 유지함.
- Sprint 중 Draw는 허용하되 Ready 진입 후 Sprint를 취소하여 Walk 또는 Idle로 전환하는 흐름을 정리함.
- Evade 중에는 ForceHolster를 유지하고 Draw·Fire·Aim·Reload 전이가 STC에서 실패하도록 구성 방향을 정리함.

### 5. StateTree와 Blueprint 적용 항목 정리

- Root의 무조건 `Draw → Ready` 전이를 제거하고 Holstered 범위에서 `STC_CanDrawWeapon`을 통과한 경우만 Ready로 전이하도록 정리함.
- Holstered에서 Reload로 직접 진입해 Draw/STC를 우회하는 전이를 제거하는 방향을 정리함.
- `STT_WeaponReady`는 손 소켓 부착 성공 후에만 `ReadyEntered`를 발행하도록 실행 순서를 명시함.
- Lower StateTree는 Sprint 상태에서만 `CancelSprint` 명령을 수락하도록 구성함.

## 확정한 설계

- 빈 Weapon Slot도 선택 가능하며 선택 결과는 맨손 상태임.
- 공격 Sequence와 공격 1회 Commit·전달 책임을 별도 Handler로 분리함.
- StateTree 전이 허용 여부는 STC가 판단하고 EntityStateMediator는 명령과 사건만 중계함.
- 게임 시작, Sprint 진입과 Evade 진입 시 Upper 상태는 Holstered를 유지함.
- Sprint 중 Draw 성공 시 Sprint를 취소하고 Walk 또는 Idle로 전환함.
- Evade 중에는 상체 무기 입력을 허용하지 않음.

## 테스트·검토 결과

- Weapon 선택 Input, Gear 활성 슬롯과 WeaponComponent 재바인딩 소스를 반영함.
- 빈 슬롯 선택, Holstered 동기화와 맨손 처리 소스를 반영함.
- Upper StateTree, Holster Task, PlayerCharacter Blueprint와 입력 에셋이 갱신된 것을 확인함.
- `ReadyEntered`, `CancelSprint` 중계와 시작 시 자동 Draw 제거 C++을 반영함.
- 최종 C++ 빌드와 전체 Blueprint Compile·PIE는 수행하지 않았으므로 통합 검증이 필요함.

- Aim·Reload STC에 Evade 차단 조건 확인.

- Weapon1·Weapon2·빈 슬롯 순환과 전환 Cooldown 회귀 테스트.
