# 2026-08-17 일일 개발 리포트

## 오늘의 목표

- 권총 발사 시점을 애니메이션 Notify와 일치시키고 발사 예외 흐름을 보강
- 빈 탄창 공격, 조준 포즈, Aim Hold/Toggle 및 카메라 Zoom 기반 구현
- 프로젝트 기획 문서와 작업 규칙을 `Astra_Docs`에 체계적으로 정리
- Codex 작업공간 ACL 문제와 Unreal 빌드 가능 여부 확인

## 완료한 작업

### 1. 권총 발사 흐름 개선

- 발사 입력 즉시 탄약과 Projectile을 처리하던 구조를 `Weapon_FireCommit` Montage Notify 시점 처리로 변경함.
- `CommitFireShot()`에서 탄약 소비, 카메라 기준 조준 방향 계산, Muzzle 기준 Projectile 생성, 발사 효과와 반동을 일괄 처리하도록 정리함.
- Notify 이전 취소 시 탄약과 Projectile이 발생하지 않도록 처리함.
- Notify 이후 몽타주 중단은 이미 발사된 탄을 정상 발사로 유지하도록 함.
- 수납·강제 수납·무기 해제 시 진행 중인 발사를 취소하고, 발사 중 재장전을 차단함.
- `OnWeaponFireFinished(bool bSucceeded)` 완료 이벤트와 Notify 누락 경고를 추가함.
- 발사되지 않던 원인이 DataAsset에 잘못 연결된 발사 몽타주였음을 확인하고 올바른 몽타주로 교체함.

### 2. 빈 탄창 자동 재장전

- `UWeaponComponent::ShouldReloadOnFireRequest()`를 추가해 탄약 사용 무기, 빈 탄창, 재장전 가능 여부를 판정하도록 함.
- 빈 탄창에서 공격하면 `Input.Ability.Primary` 대신 `Input.Ability.Reload`를 전달하도록 `APlayerCharacter::RequestWeaponFire()`를 수정함.
- 무기가 Ready 상태가 아니면 `PendingWeaponAction::Reload`를 저장하고 Draw 완료 후 재장전으로 이어지도록 구성함.

### 3. 발사 중 조준 포즈 유지

- 발사 시 Upper Body 몽타주가 Aim Offset 결과를 덮어써 팔과 어깨가 정면 자세로 돌아가던 원인을 확인함.
- AnimGraph 순서를 `Pistol Idle → UpperBody Slot → Aim Offset → Layered Blend Per Bone → Control Rig/FABRIK`으로 변경함.
- 발사 중에도 현재 Aim Pitch가 유지되는 것을 확인함.
- 허리 굽힘 부족에 따른 왼팔 머리 관통, Idle/Fire 기준 포즈 불일치와 Idle 루프 끊김은 후속 이슈로 기록함.

### 4. Aim C++ 기반 구현

- 무기별 `Hold/Toggle` 입력 모드, Aim FOV, FOV 보간 속도를 DataAsset에서 설정할 수 있도록 기반을 추가함.
- `PlayerCharacter`에 Aim 시작·종료 요청 함수를 추가하고 Pending Aim 처리와 StateTree 명령 전달을 연결함.
- `WeaponComponent`에 Aim 가능 조건과 설정 조회 기능을 추가함.
- 조준 상태에서는 무기별 FOV로, 해제 시 기본 FOV로 보간하도록 연결함.
- UHT와 C++ 컴파일, DLL 링크를 포함한 `Astra_SoulLinkEditor Win64 Development` 빌드 성공을 확인함.

### 5. 기획 문서와 작업 규칙 정리

- 시나리오 및 NPC 행동 설계 자료와 기존 대화 기록을 기반으로 프로젝트 기획 문서를 재구성함.
- 프로젝트 문서, Unreal 일반 지식, Troubleshooting, ADR, Inbox, Archive를 분리함.
- 세계관, 인물, NPC 행동, 전투 성향, 팩션, 소울링크, 생존 시스템 문서를 추가함.
- 설계 문서 상단에 Mermaid 시각화를 추가하고 근거 없는 의도·수치·정책은 비워 둠.
- Blueprint/C++ 작업 분담, Blueprint 전체 노드 순서 제공, StateTree Condition·Task·GA 책임, Mediator/EventBus 통신, 무기 데이터 소유권 및 빌드 규칙을 `00 Work Rules`에 정리함.
- 남은 애니메이션·조준·IK·전투 취소 이슈를 `09-Open-Issues.md`에 모아 기록함.

### 6. ACL 및 빌드 환경 점검

- Astra 프로젝트 NTFS 권한에는 명시적 Deny가 없고 현재 사용자에게 수정 권한이 있음을 확인함.
- `apply deny-read ACLs` 오류는 프로젝트 권한이 아니라 중첩된 작업공간과 OneDrive 재분석 경로가 포함된 Codex 샌드박스 구성 충돌로 판단함.
- Unreal 코드와 문서 저장소를 각각 `Astra_Unreal`, `Astra_Docs` 작업공간으로 분리하도록 정리함.
- 실행 중인 Unreal Editor가 핫리로드 DLL을 점유하면 `UnauthorizedAccessException` 또는 `LNK1104`가 발생함을 확인함.
- 에디터 종료 후 Development Editor 빌드가 정상 완료되어 프로젝트 ACL 자체에는 문제가 없음을 검증함.

## 확정한 설계

- 실제 발사와 탄약 소비는 `Weapon_FireCommit` Notify에서만 수행함.
- 빈 탄창 공격은 Fire 실패로 끝내지 않고 Reload 입력으로 변환함.
