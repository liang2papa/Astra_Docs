# 2026-09-30 일일 개발 리포트

## 오늘의 목표

- NPC GA Context null 원인 해결
- 반복 공격·타겟 회전·추적 복귀 구현

## 완료한 작업

### 1. NPC Context 반환 문제 해결

- BP_NPCCharacter의 GetContext 오버라이드 반환 누락 확인
- 부모 EntityContext 반환 연결 또는 불필요한 오버라이드 제거 안내
- 사용자의 Context 복구 후 첫 발 정상 발사 확인

### 2. 첫 발 이후 반복 공격 누락 분석

- Brain Attack 상태 진입 시 일회성 AttackStarted 발신 구조 확인
- Attack 상태 유지 중 다음 공격 명령이 생성되지 않는 원인 확인

### 3. 지속 공격·회전 C++ 반영

- Brain용 NPC Combat Attack 지속 Task 추가
- Ready 복귀·기존 공격 종료·다음 공격 가능 상태에 따른 재요청 경로 구현
- 타겟 Focus와 몸 방향 정렬 후 공격 요청 처리
- 빈 탄창의 Reload 전환과 공격 이탈·타겟 상실 시 입력·Focus 정리

### 4. StateTree·Blueprint 연결 안내 작성

- Attack → Chase 사거리 Condition의 AIController 바인딩 누락 확인
- NPC Upper 공격 Task의 EnterState 1회 GA 활성화·Tick 완료 대기 흐름 정리
- Upper Ready 진입 Task의 ReadyEntered 발행과 Player·NPC 공유 가능성 확인
- NPC 공격 반복·회전·추적 복귀 연결 안내서 작성

## 확정한 설계

- 실제 발사에 기존 InputBuffer → Upper StateTree → GA → WeaponComponent 경로 사용
- NPCBrain의 지속 Task에서 반복 공격 판단
- Ready Task는 각 Entity의 Context 바인딩으로 공유

## 테스트·검토 결과

- 사용자 확인: Context 복구 후 첫 발 정상

- 당일 수정분의 빌드는 사용자 수행으로 지정, 최종 완료 기록 미확인
