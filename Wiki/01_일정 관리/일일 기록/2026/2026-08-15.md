# 2026-08-15 일일 개발 리포트

## 오늘의 목표

- 권총 소지 상태의 상체 조준을 연결
- 카메라 Pitch와 총기/팔 보정 방향 결정
- 기존 DOCX Wiki를 Markdown 문서 저장소로 이전

## 완료한 작업

### 조준 회전과 AnimBP

- 무기를 손에 든 상태에서 Controller Desired Rotation을 사용하는 이동 방향을 적용했습니다.
- AnimBP에서 `BaseAimRotation - ActorRotation`의 상대 Pitch를 계산했습니다.
- AimPitch에 Clamp와 `FInterpTo` 보간을 적용하는 구조를 구성했습니다.
- `AO_Pistol`을 Pistol Idle 상체 포즈에 연결했습니다.
- 카메라를 조금만 움직여도 Aim 애니메이션이 끝 샘플로 바뀌던 원인을 확인했습니다.
- Aim Offset 축 Min/Max가 `-1, 1`이었던 것을 실제 각도 범위로 확장해 끊김을 해결했습니다.

### 카메라·상체 제한 설계

- 카메라 Pitch를 PlayerCameraManager에서 약 ±70도로 제한하는 방향을 확정했습니다.
- Aim Offset 샘플 범위와 실제 입력 Clamp 범위를 분리하기로 했습니다.
- 상체 Aim Offset은 대략적인 조준 방향, 총기/오른팔 Control Rig는 최종 시각 정렬, Projectile은 Muzzle→AimTarget 계산을 사용하는 3단계 구조로 정리했습니다.

### 왼손 IK 계획

- 권총 Static Mesh에 `LeftHandGrip` Socket을 추가하는 방향을 확정했습니다.
- 왼손 IK는 오른손과 무기 보정 이후에 적용하기로 했습니다.
- Draw/Holster 중에는 IK Alpha를 끄거나 Notify/Curve로 보간해야 함을 정리했습니다.

### 카메라 시스템 결정

- 현재 `CameraBoom + FollowCamera + PlayerCameraManager` 구성을 유지합니다.
- PlayerCameraManager를 최종 View와 Pitch 제한, Camera Modifier의 중심으로 사용합니다.
- 실험적 Gameplay Cameras 플러그인으로의 교체는 현재 범위에서 제외했습니다.

### 문서화

- `Project Wiki_Ver2.docx`의 273개 문단과 4개 표를 구조적으로 추출했습니다.
- 오래된 Unity 규칙과 현재 Unreal 규칙을 분리했습니다.
- Architecture, Development Rules, StateTree/GAS, Locomotion, Weapon, Animation/Aiming, Roadmap, Editor Workflows 문서로 재편했습니다.
- 상세 일일 리포트용 Markdown 구조를 추가했습니다.

## 확정한 설계

- 카메라 Pitch 제한은 PlayerCameraManager가 담당합니다.
- Aim Offset은 각도 단위 입력을 사용하고 입력만 ±70도 범위로 제한합니다.
- 총구의 실제 탄도와 캐릭터 포즈 보정은 분리합니다.
- Git은 `Astra_Docs` 문서 전용으로 사용하고 Unreal 프로젝트는 Plastic SCM을 유지합니다.
