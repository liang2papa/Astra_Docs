# 해결된 이슈

> 최종 갱신: 2026-08-28  
> 목적: 구현 또는 에디터 검증이 완료되어 더 이상 남은 작업으로 추적하지 않는 문제를 기록한다.

## 애니메이션

### ANIM-001. 상하 조준 시 허리 굽힘 부족과 왼팔 머리 관통

- 상태: 해결 완료
- 기존 현상: 상하 조준에서 척추 굽힘이 부족하고 왼팔이 머리 또는 몸통을 관통했다.
- 완료 기준: 허용된 카메라 Pitch 범위에서 조준 자세와 총구 방향이 정상 유지되는 것을 확인했다.
- 완료 확인: 2026-08-28 사용자 확인

### ANIM-002. Pistol Idle과 Fire 포즈 불일치 및 Idle 루프 끊김

- 상태: 해결 완료
- 기존 현상: Idle 반복 경계와 Idle↔Fire 전환에서 팔·어깨·총기가 튀었다.
- 완료 기준: Idle 루프와 Fire 전환이 눈에 띄는 단절 없이 재생되는 것을 확인했다.
- 완료 확인: 2026-08-28 사용자 확인

### ANIM-003. AimOffset Pitch 증가에 따른 왼손 이탈

- 상태: 해결 완료
- 원인: 완성된 무기 애니메이션 위에 FABRIK을 추가하여 기존 손·팔 관계를 다시 강제로 보정했다.
- 해결: 완성 애니메이션 경로의 중복 FABRIK을 제거했다.

## 무기

### WPN-001. 빈 탄창 공격 요청의 자동 재장전

- 상태: 해결 완료
- 발사 요청 시 탄약이 없고 재장전할 수 있으면 `Input.Ability.Reload`로 라우팅한다.
- Holstered 상태에서는 Draw 완료 후 Reload를 Pending Action으로 실행한다.
- 재장전 불가능한 무기와 최대 탄창 상태는 Reload로 잘못 진입하지 않는다.
- 완료 확인: 2026-08-28 사용자 확인

### WPN-008. Draw 정렬 대기 Blueprint 연결

- 상태: 해결 완료
- `Abs Delta Yaw <= WeaponDrawAlignmentToleranceYaw` 순서로 비교하도록 뒤집혀 있던 입력을 수정했다.
- 허용 오차 안에서 `NotifyWeaponDrawAlignmentCompleted`가 호출되고 무기 부착과 Pending Action이 이어지는 것을 확인했다.

### WPN-009. 총열 시각 보정과 초근접 제한

- 상태: 해결 완료
- Pitch/Yaw 최대 보정값을 각각 `30°`로 설정하고 Yaw 보간 Target 연결 오류를 수정했다.
- 평사·상향·하향 조준에서 논리 발사 방향과 총구 방향이 일치하며, 보정 해제 시 값이 0으로 복귀한다.
- Fire Montage 중 총구선의 일시적 이탈은 시각 반동이며 Projectile 방향은 유지되고 Montage 종료 후 다시 정렬된다.

## 기타 해결 기록

- 카메라 Pitch Min/Max가 비무장·권총 상태에 따라 적용되는 것을 확인했다.
- 카메라 레이와 총구 방향을 분리하여 조준점 기준으로 Projectile이 발사되도록 수정했다.
- Fire Montage가 고정된 팔·어깨 포즈로 돌아가던 문제는 AnimGraph 순서를 조정하여 해결했다.
- 잘못된 Fire Montage가 Weapon DataAsset에 연결되어 Projectile이 생성되지 않던 문제를 수정했다.
- Mantle 완료 후 Falling/Hanging으로 되돌아가던 문제와 이전 위치 재매달림 문제를 해결했다.
