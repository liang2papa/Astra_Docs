## 정정·해석 기준

- ScrollBox: 여러 자식 지원. 기존 단일 자식 설명 정정
- Handled: UI 입력 전파 응답. 게임 입력 전체 차단 보장으로 확대하지 않음
- Soft 에셋 경로 존재와 로드 완료 구분
- SpinBox Max 설정과 Blueprint 멤버 변수 저장 구분
- Equip enum 기본값 전달: 텍스트 변환과 멤버 저장 구분
- 팝업 화면 크기와 마우스 위치는 같은 좌표계 사용
- 근접 크로스헤어 제외 제안은 최신 확정안 아님
- 과거 비동기 로딩 예제와 현재 WorldItem 구현 구분
- 완료된 기본 HUD·Stack 분할과 남은 전체 회귀·Reserved UI를 구분
