# 동적 위젯 생성과 데이터 갱신

## 설계 의도

위젯 생성과 데이터 갱신 분리. 하위 위젯은 자신의 표시와 입력 전달만 담당

## Grid와 배열 구분

| 변수 | 타입 | 역할 |
|---|---|---|
| InventorySlotsGrid | UniformGridPanel 참조 | 화면 배치 |
| InventorySlotWidgetList | WBP_InventorySlot 참조 배열 | SlotIndex로 생성 위젯 조회 |

My Blueprint → + Variable → WBP_InventorySlot Object Reference → 컨테이너를 Array로 변경

7열 예시: Row = Integer Divide(Index, 7), Column = Index % 7

배열 인덱스와 Inventory SlotIndex 일치 유지

## 초기값과 표시값

- InitializeSlot: InSlotIndex를 멤버 SlotIndex에 저장
- SetSlotData: ItemInstance·사용 가능 여부·아이콘·수량 갱신
- bUsableSlot: Component가 전달한 값 사용. Widget에 기본 Capacity 하드코딩 금지
- 디자이너에서 배치한 장비 슬롯: Instance Editable인 EquipmentSlot 값 지정
- 위젯 이름을 바꾸는 것과 EquipmentSlot enum 설정은 별개

## 동적 선택 메뉴

- 옵션 위젯: EquipmentSlot 저장 + 버튼 텍스트 + OnSlotSelected
- 선택 메뉴: CurrentInventorySlot 저장 + CompatibleSlots만큼 옵션 생성
- 전체 메뉴: OnEquipmentSlotSelected 수신 → RequestEquipItem
- 표시용 Switch에 입력을 전달해도 멤버 변수에 자동 저장되지 않음

확인된 오류: InitializeOption의 Set EquipmentSlot 누락 → 클릭 시 기본 enum인 Head 전달

## 전체 노드 실행 순서

```text
Inventory 초기화
→ Clear Children(InventorySlotsGrid)
→ Clear(InventorySlotWidgetList)
→ For Loop(Index=0..최대 표시 슬롯 수-1)
  → Create Widget(WBP_InventorySlot, Owning Player)
  → InitializeSlot(InSlotIndex=Index)
  → 좌·우클릭 Dispatcher Bind
  → Array Add(Item=Create Widget.ReturnValue)
  → Add Child to Uniform Grid(Content=같은 ReturnValue,
                              Row=Index/열 수, Column=Index%열 수)
→ Completed → 초기 데이터 동기화

DisplayInventorySlot(SlotIndex, ItemInstance, bUsableSlot)
→ InventorySlotWidgetList[SlotIndex]
→ SetSlotData(SlotIndex, ItemInstance, bUsableSlot)

OpenSelectionMenu(InInventorySlot, CompatibleSlots)
→ Set CurrentInventorySlot = InInventorySlot
→ Clear Children(VerticalBox_Options)
→ For Each Loop(CompatibleSlots)
  → Create Widget(WBP_EquipmentSlotOption, Owning Player)
  → InitializeOption(Array Element)
    → Set EquipmentSlot = InEquipmentSlot
    → Switch on EEquipmentSlot → Text_SlotName.SetText
  → Bind Event to OnSlotSelected(Target=새 옵션)
  → Add Child to Vertical Box(Content=새 옵션)
→ Completed → Visible → Layout Prepass → 위치 계산

옵션 Button.OnClicked
→ Get EquipmentSlot
→ Call OnSlotSelected(EquipmentSlot)
→ 선택 메뉴 HandleSlotSelected
→ Call OnEquipmentSlotSelected(CurrentInventorySlot, SelectedEquipmentSlot)
→ 전체 메뉴 HandleEquipmentSlotSelected
→ Get Menu Component → RequestEquipItem(InventorySlot, EquipmentSlot)
  ├─ 성공 → CloseTransientPanels → 임시 선택값 초기화
  ├─ 일반 실패 → DisplayActionFailure → 메뉴 유지
  └─ 메뉴 닫힘·연결 부재 → 요청 거부, 데이터 변경 없음

취소·메뉴 닫기
→ 선택 메뉴 Collapsed → CurrentInventorySlot = -1
```
