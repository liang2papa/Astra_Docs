# 패널과 자유 배치

```text
UserWidget
└─ Canvas Panel — 화면 위치
   ├─ Overlay — 체력 바 + 텍스트 겹침
   ├─ Horizontal Box — 가로 자동 정렬
   └─ Canvas Panel — 묶음 내부 자유 배치
```

## 설계 의도

HUD 묶음의 화면 위치와 내부 아이콘·숫자의 상대 위치를 각각 조정

## 기본 개념

| Unreal | 역할 | Unity의 가까운 개념 |
|---|---|---|
| UserWidget / Widget Blueprint | 화면의 위젯 계층과 이벤트 보관 | UI Prefab + UI 스크립트 |
| Designer | 위젯 배치·속성 편집 | Prefab 편집 |
| Event Graph | 표시 값과 입력 처리 | Visual Scripting |
| Canvas Panel | 좌표·크기·앵커 기반 배치 | RectTransform 기반 자유 배치 |
| Horizontal / Vertical Box | 가로 / 세로 자동 배치 | Layout Group |
| Overlay | 여러 자식 겹침 | 같은 영역의 UI 중첩 |
| SizeBox | 자식의 요청 크기 제어 | Layout Element의 크기 지정 |

`WBP_PlayerHUD` 자체는 Canvas Panel이 아닌 UserWidget

자식의 Slot 종류는 직계 부모 패널로 결정

## Auto·Fill·Padding

- Auto: 자식이 요청한 크기 사용
- Fill: 부모의 남은 공간을 비율에 따라 배분
- Alignment: 배정된 슬롯 안의 자식 정렬
- Padding: 슬롯 내부 여백
- Canvas Slot의 Auto Size: 해당 위젯의 Desired Size 사용
- Render Transform: 레이아웃 이후의 시각 이동·회전·확대

가로로 붙이는 아이콘·숫자: 둘 다 Auto + Padding

아이콘 왼쪽 / 숫자 오른쪽: 부모 폭 지정 → 아이콘 Auto → 숫자 Fill + Right

## Canvas 안에 Canvas 배치

```text
WBP_PlayerHUD
└─ CanvasPanel_Root
   └─ CP_WeaponInfo
      ├─ IMG_WeaponIcon
      └─ TXT_AmmoValue
```

1. Designer → Palette → Canvas Panel을 루트 아래에 추가
2. 이름: `CP_WeaponInfo`
3. 기존 Image·Text를 안쪽 Canvas로 이동
4. 두 위젯의 Details → Slot이 `Canvas Panel Slot`인지 확인
5. CP_WeaponInfo의 Size X/Y와 화면 위치 지정
6. 내부 Image·Text의 Position / Size 개별 지정

기존 위젯 이동 시 변수와 이벤트 연결 유지 여부 확인

## 전체 배치 순서

```text
루트 Canvas
→ CP_WeaponInfo의 Anchors / Alignment / Position / Size 지정
→ 내부 IMG_WeaponIcon의 Position / Size 지정
→ 내부 TXT_AmmoValue의 Position / Size 지정
→ Compile / Save
→ Designer Screen Size 변경
→ PIE에서 묶음 위치와 내부 상대 위치 확인

자유 배치 불가
→ 직계 부모와 Slot 종류 확인
→ Horizontal Box 아래라면 Canvas Panel로 이동
```
