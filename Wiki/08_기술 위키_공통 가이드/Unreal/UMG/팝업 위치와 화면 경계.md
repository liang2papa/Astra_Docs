# 팝업 위치와 화면 경계

## 설계 의도

인벤토리·장비 메뉴가 화면 우측·하단을 넘어가지 않도록 위치 보정

## 적용 전제

- 팝업: 화면 전체를 덮는 루트 Canvas의 직접 자식
- Canvas Slot Anchors = 좌상단, Alignment = (0,0)
- 위치·화면 크기·팝업 크기는 동일한 UI 좌표계
- 부모 Canvas가 화면 일부이거나 Transform이 있으면 부모 Geometry의 로컬 좌표로 변환 후 계산

마우스: Get Owning Player → Get Mouse Position Scaled by DPI

화면: Get Viewport Widget Geometry → Get Local Size

물리 픽셀인 Get Viewport Size를 DPI 보정된 마우스 좌표와 그대로 비교하지 않음

## 크기 확정

- 고정 크기: SizeBox Width / Height Override 값 사용
- 동적 크기: 버튼 생성·텍스트 갱신 → Visible → Force Layout Prepass → Get Desired Size
- Force Layout Prepass: 위젯 계층의 Desired Size 재계산. [Epic API](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/UMG/UWidget/ForceLayoutPrepass)
- Get Desired Size는 요청 크기. 부모가 실제 크기를 제한하면 그 제약도 반영 필요

## 좌표 계산

```text
FitsRight  = MouseX + Gap + MenuWidth  <= ViewportWidth
FitsBottom = MouseY + Gap + MenuHeight <= ViewportHeight

X = Select Float(FitsRight,
                 True: MouseX + Gap,
                 False: MouseX - MenuWidth - Gap)
Y = Select Float(FitsBottom,
                 True: MouseY + Gap,
                 False: MouseY - MenuHeight - Gap)

X = Clamp(X, 0, Max(0, ViewportWidth - MenuWidth))
Y = Clamp(Y, 0, Max(0, ViewportHeight - MenuHeight))
```

확인된 오류: True/False 좌우 결과 반전, Y 계산에 Width 사용, 화면 초과 분기에서 더하기 사용

화면보다 메뉴가 큰 경우: Clamp만으로 전부 표시 불가. 메뉴 크기 제한·스크롤은 별도 결정

## 장착 위치 하위 메뉴

마우스 대신 현재 Context Menu의 위치를 기준으로 배치

- 오른쪽 후보: ContextX + ContextWidth + Gap
- 오른쪽 공간 부족: ContextX - SelectionWidth - Gap
- Y 후보: ContextY
- 마지막에 화면 범위 Clamp

## 전체 노드 실행 순서

```text
DisplayInventoryContextMenu 또는 DisplayGearContextMenu
→ 메뉴 데이터·버튼 Visibility 설정
→ 팝업 Visible
→ Force Layout Prepass(Target=팝업)
→ Get Desired Size → Width / Height
→ Get Mouse Position Scaled by DPI
  ├─ 실패 → 팝업 Collapsed, 위치 적용 중단
  └─ 성공 → Get Viewport Widget Geometry → Get Local Size
→ FitsRight / FitsBottom 계산
→ Select Float 두 개 → Clamp X/Y
→ Make Vector2D
→ Slot As Canvas Slot(Target=팝업)
→ Set Position

DisplayEquipmentSlotSelection
→ OpenSelectionMenu → 옵션 생성 완료
→ Visible → Force Layout Prepass → Get Desired Size
→ Context Menu 위치·폭 조회
→ 우측 후보 계산 → 공간 부족 시 좌측 후보
→ X/Y Clamp → CanvasSlot.SetPosition

닫기·취소
→ Context Menu와 하위 메뉴 Collapsed
```
