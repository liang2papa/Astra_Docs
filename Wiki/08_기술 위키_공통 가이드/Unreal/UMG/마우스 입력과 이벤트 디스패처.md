# 마우스 입력과 이벤트 디스패처

```text
하위 슬롯 클릭
→ Dispatcher: 슬롯 식별자 발행
→ 상위 메뉴 Custom Event 수신
→ MenuComponent에 행동 요청
→ Component 결과를 Widget에 표시
```

## 설계 의도

하위 슬롯의 InventoryComponent·GearComponent 직접 의존 제거

## 클릭 이벤트 위치

Designer → 클릭 영역 Border 선택 → Details → Events → On Mouse Button Down → +

`Go To` 표시: 이미 생성된 이벤트로 이동

일반 함수 검색으로 추가하는 노드와 Override·위젯 이벤트 구분

## 입력 응답

- Border: Visible
- 장식용 아이콘·텍스트: Not Hit-Testable (Self Only), 이전 표기 Self Hit Test Invisible
- Handled: 현재 UI 입력 처리 완료
- Unhandled: 처리하지 않은 입력을 상위로 전달
- Handled는 UI 이벤트 전파 결과. 모든 Enhanced Input·게임 입력 차단을 단독 보장하지 않음
- 메뉴 열기·닫기의 Input Mode, Look Input 차단·복원은 상위 UI 제어 계층에서 별도 관리

## Dispatcher 정의와 Bind

하위 Widget의 My Blueprint → Event Dispatchers → +

`OnInventorySlotLeftClicked` 입력: `ClickedSlotIndex : Integer`

상위 Widget의 초기화에서 `Bind Event to OnInventorySlotLeftClicked` 추가

- Target: 생성하거나 배치한 실제 슬롯 인스턴스
- Event: 상위 Widget의 `HandleInventorySlotLeftClicked` Custom Event
- 입력: Dispatcher와 같은 이름·타입
- 창을 열 때마다 같은 인스턴스에 Bind하지 않음
- 재생성한 인스턴스에는 새로 Bind

장비 슬롯은 Integer 대신 `EEquipmentSlot` 사용

## 전체 노드 실행 순서

```text
초기화
→ 슬롯 인스턴스 확보
→ Bind Event to OnInventorySlotLeftClicked(Target=슬롯)
→ Bind Event to OnInventorySlotRightClicked(Target=슬롯)

Border.OnMouseButtonDown(MyGeometry, MouseEvent)
→ Get Effecting Button(MouseEvent)
→ Equal Key(Left Mouse Button)
  ├─ True → Call OnInventorySlotLeftClicked(SlotIndex) → Return Handled
  └─ False → Equal Key(Right Mouse Button)
      ├─ True → Call OnInventorySlotRightClicked(SlotIndex) → Return Handled
      └─ False → Return Unhandled

HandleInventorySlotLeftClicked(ClickedSlotIndex)
→ Get Menu Component
→ SelectInventoryItem(ClickedSlotIndex)
→ 표시 이벤트 → Tooltip 표시

HandleInventorySlotRightClicked(ClickedSlotIndex)
→ Get Menu Component
→ OpenInventoryContextMenu(ClickedSlotIndex)
→ 표시 이벤트 → Context Menu 표시

행동 요청 실패
→ 실패 결과 표시 경로 확인
→ Item 상태를 Widget에서 임의 변경하지 않음

메뉴 닫기·취소
→ Tooltip / Context Menu / 선택 Menu / Dialog 숨김
→ 임시 선택값 초기화
→ 상위 UI 제어 계층의 입력 모드 복원
```
