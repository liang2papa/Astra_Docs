# 슬롯 크기와 스크롤

```text
ScrollBox_Inventory
└─ InventorySlotsGrid (UniformGridPanel)
   └─ WBP_InventorySlot × N
      └─ SizeBox_Root
         └─ Border_IconBG
            └─ Overlay_Icon
               ├─ Image_Icon
               ├─ Border_IconOutline
               └─ Text_Quantity
```

## 설계 의도

슬롯의 정사각형 유지. 인벤토리 목록의 위·아래 스크롤 지원

## 한 자식 컨테이너와 여러 자식 컨테이너

- SizeBox·Border: 직접 자식 하나
- 여러 요소를 넣을 때: Overlay 또는 Box 패널을 중간에 배치
- Overlay: 아이콘·외곽선·수량을 같은 공간에 겹침
- ScrollBox: 여러 자식 지원. 이 구성에서는 Grid 하나를 넣어 목록 전체 스크롤

과거 대화의 ScrollBox 단일 자식 설명 정정. [Epic UScrollBox](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/UMG/UScrollBox) 기준 여러 위젯 보관 가능

## 크기 설정

1. 공통 슬롯 Widget의 루트에 SizeBox 배치
2. Width Override / Height Override에 같은 값 지정. 대화 예시 `64 / 64`
3. Border 선택 → Size Box Slot → Horizontal / Vertical Alignment = Fill
4. Border Padding = 0부터 시작
5. Grid 안의 슬롯 Widget → Uniform Grid Slot → Horizontal / Vertical Alignment = Center
6. 아이콘·외곽선은 Overlay Slot에서 Fill. 수량은 우하단 정렬

SizeBox는 레이아웃 요청 크기 제어. 부모가 너무 작은 영역을 배정하면 부모 크기·정렬·Clipping도 확인

## 스크롤 설정

- Orientation = Vertical
- Consume Mouse Wheel = When Scrolling Possible
- Scroll Bar Visibility = Visible
- ScrollBox 영역의 높이를 제한해 내용이 넘을 공간 확보
- Allow Right Click Drag Scrolling: 우클릭 메뉴와 입력 충돌을 확인한 뒤 사용 여부 선택

기본 휠 스크롤과 사용자 정의 좌클릭 드래그는 별도 기능

## 전체 배치·입력 순서

```text
슬롯 SizeBox 크기 지정
→ Grid Slot Center 정렬
→ Grid 전체를 ScrollBox 아래 배치
→ ScrollBox 표시 영역 크기 지정
→ Compile / Save
→ 목록이 표시 영역보다 긴 상태로 PIE
→ 휠 스크롤 확인
→ 우클릭 메뉴와 드래그 입력 충돌 확인

아이콘·외곽선·수량 추가
→ Border의 단일 자식으로 Overlay 배치
→ Overlay 안에 여러 표시 위젯 배치
```
