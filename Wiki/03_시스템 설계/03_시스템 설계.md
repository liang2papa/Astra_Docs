# 03_시스템 설계

Astra 프로젝트에 실제로 적용하는 프로그래밍 구조, 데이터 소유권과 시스템 간 실행 흐름을 관리합니다.

```mermaid
flowchart TD
    GameMode["GameMode"] --> PlayerController["PlayerController"]
    GameMode --> PlayerState["PlayerState: ASC·AttributeSet"]
    GameMode --> Pawn["PlayerCharacter / Avatar"]
    PlayerController -->|Possess| Pawn
    PlayerController --> Camera["PlayerCameraManager"]
    Pawn --> Context["EntityContext"]
    Camera --> Context
    PlayerController --> Intent["GameplayTag Intent·Event"]
    Intent --> StateTree["Base / Upper StateTree"]
    StateTree --> GAS["Gameplay Ability System"]
    GAS --> Components["Weapon·Locomotion·Health Component"]
    Context --> StateTree
    Context --> GAS
    Mediator["EntityStateMediator / EventBus"] <--> StateTree
    PlayerState --> GAS
```
