# Astra Docs

`Astra_Docs`는 Unreal Engine 5.8 기반 TPS 프로젝트 **아스트라: 영혼결속**의 설계, 구현 기준, 작업 기록을 관리하는 문서 저장소입니다.

Unreal 프로젝트 소스와 콘텐츠는 Plastic SCM에서 관리하고, 이 저장소는 문서 전용으로 사용합니다.

## 문서 운영 원칙

1. 현재 Unreal 구현과 확정된 설계를 본문에 기록합니다.
2. 검토 중인 내용은 `검토 중`, 아직 없는 기능은 `미구현`으로 표시합니다.
3. Unity 시절 자료는 설계 의도를 보존하기 위한 부록이며 Unreal 규칙보다 우선하지 않습니다.
4. 일정표에는 일일 작업의 요약만 기록하고, 상세 작업·결정·잔여 이슈는 `Reports/Daily`에 기록합니다.
5. Unreal 소스 및 콘텐츠 경로는 프로젝트 루트 기준으로 표기합니다.
