## 문서 운영 원칙

1. 각 번호 폴더의 같은 이름 문서를 해당 업무 영역의 허브로 사용합니다.
2. 허브에는 상세 내용을 복제하지 않고 개요와 주요 문서 링크만 둡니다.
3. Astra에 실제 적용한 내용은 게임 기획과 시스템 설계에 기록합니다.
4. 다른 프로젝트에서도 재사용할 일반 지식은 기술 위키·공통 가이드에 기록합니다.
5. 중요한 선택과 이유는 시스템 설계의 ADR에 기록합니다.
6. 검토 중인 내용은 `검토 중`, 아직 구현하지 않은 기능은 `미구현`으로 표시합니다.
7. 설계 의도에 근거가 없으면 추정하지 않고 비워 둡니다.
